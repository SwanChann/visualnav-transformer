\chapter{全文总结与未来展望}

\section{全文工作总结}

本文以 \textit{visualnav-transformer} 项目为研究起点，以 NoMaD 为高层核心算法，以云深处 Lite3 四足机器人为主要部署对象，围绕“基于动作扩散策略的足式机器人视觉目标导航与探索”展开了系统化研究。与以往只停留在模型离线指标的视觉导航研究不同，本文从一开始就把研究目标设定为“算法、系统与平台三者是否能够形成真正闭环、可运行、可分析的整体方案”，并按照“算法层—系统层—平台层”的分层研究路径逐步推进。围绕这一目标，本文主要完成了以下四方面工作。

第一，从项目代码出发，对 NoMaD 的整体结构、训练流程与推理流程进行了系统梳理\cite{nomad2023,diffusionpolicy2023}。本文明确了视觉编码器、距离预测头与扩散策略头之间的共享条件空间关系，指出视觉编码器升级不是“仅替换前端”而是对整条高层决策链路的重构，并以此为依据设计了后续的视觉编码器实验方案。与此同时，本文还整理出统一推理模块，把调度器种类、采样步数、CFG 权重、视觉编码器配置与 checkpoint 路径等关键参数收口到同一接口之下，使算法层、系统层与平台层能够在同一套推理入口上持续衔接。

第二，面向部署需求对原始 NoMaD 进行了算法级优化并在 24 个测试 case 上完成了统计实验\cite{ddpm2020,ddim2020,cfg2022}。基线实验建立了原始模型的推理规模参考；DDIM 实验表明，扩散策略在采样步数压缩至 2 步时仍能保持较低的 MSE 与可接受的前向推进能力，同时推理加速近 5 倍，因而 DDIM-2 成为最具部署潜力的候选配置；CFG 实验表明，目标条件增强在 $w=1.0$ 附近能带来有限的前向推进收益，但推理延迟几乎翻倍，且 $w$ 过大会引发轨迹偏移与横向摆动上升，因此 CFG 更应被视为可调部署旋钮而非固定默认项；视觉编码器第一阶段筛选实验表明，DINOv2-Small\cite{dinov2_2023} 相比原始 EfficientNet-B0\cite{efficientnet2019} 在轨迹前向推进、横向稳定性和推理稳定性上均显示出潜力，但由于与距离预测头存在强耦合，其最终部署价值仍需闭环验证进一步确认。

第三，围绕足式闭环需求构建了分层系统\cite{hwangbo2019anymal,lee2020learning}。本文将 Lite3 仿真与真机的共用逻辑划分为推理层、任务组织层、中层控制层与平台执行层，并落实为统一推理模块、状态机模块、导航主机模块、平台接口模块和运行会话模块；在此基础上，通过状态机显式组织 \texttt{idle}、\texttt{stand}、\texttt{navigate}、\texttt{explore}、\texttt{recovery} 与 \texttt{estop} 等状态，通过导航主机承担任务队列与后端切换职责，使同一高层 NoMaD 可以同时驱动单目标导航、探索模式与多目标任务，而无需为每类任务维护独立的高层算法。MuJoCo\cite{mujoco2012} 闭环实验进一步验证了这一设计在 easy、medium、hard 地图上可稳定运行，且 DDIM-2 与 CFG$w=1.0$ 配置能够迁移进入仿真闭环，说明算法层结论在系统层仍然成立。

第四，面向 Jetson Orin 与 Lite3 平台形成了完整的真机部署方法。本文提出了“Orin 独立调试—Orin 与 Lite3 联动”分阶段流程，明确了相机读取、NoMaD 加载、推理基准、桥接通讯、起立测试、低速测试和交互式导航的验证顺序；设计了统一的 Lite3 真机桥接层，把高层 motion command 映射为底层速度指令并维护 UDP 心跳与超时保护；区分了可视化模式与无可视化模式，使调试阶段最大化可观测性，正式运行阶段最大化实时稳定性；并围绕 \texttt{captures/}、\texttt{goal\_views/} 和 \texttt{fpv/} 三类图像记录设计了可追溯的实验证据机制。与此同时，本文所配套的《Orin 上 Lite3 真机部署完整教程》经过对照实际代码的逐项核对已订正了启动即自动起立、桥接默认限幅偏激进等关键安全口径。

综合四方面工作可以看出，本文的价值并不在于提出一个全新的算法模块，而在于完成了一次从算法论文结果到可复现系统方案的系统化整理与扩展：在算法层回答了“扩散策略是否值得继续用于真实系统”，在系统层回答了“高层生成式策略如何被状态机与导航主机稳定组织”，在平台层回答了“这套系统能否在边缘计算与足式真机约束下保持有效”。

\section{本文主要创新点}

结合上述工作，本文的主要创新点可以归纳为以下三方面。

\begin{enumerate}
    \item \textbf{面向部署的 NoMaD 推理优化与 backbone-suite 公平对照框架}：以同一统一推理接口系统比较 DDPM/DDIM 采样器与不同 CFG 权重，并在 timm\cite{timm2019} 统一主干库基础上搭建视觉编码器替换实验框架，覆盖 EfficientNet-B0、DINOv2-Small、ConvNeXt-Tiny\cite{convnext2022} 与 ResNet-50\cite{resnet2016}，使算法改动能够以统计稳定的方式进入候选筛选，而不是停留在零散调参层面。
    \item \textbf{以状态机与导航主机为核心的分层闭环架构}：将推理参数、任务组织、中层控制与平台后端严格解耦，使同一套高层 NoMaD 推理与同一套状态机可以在 MuJoCo 仿真后端与 Lite3 真机后端之间无缝切换，并天然支持单目标导航、探索模式与多目标任务三类高层运行方式。
    \item \textbf{Orin 与 Lite3 真机部署的完整工程方案}：提出独立调试—联动调试两阶段部署流程，实现可复用的 Lite3 真机桥接层、分级安全机制与 \texttt{captures/goal\_views/fpv/} 图像证据链，并形成一套经过与实际代码逐项核对的部署教程，降低了后续研究者在该平台上复现与扩展的门槛。
\end{enumerate}

\section{研究不足与讨论}

必须指出的是，本文的工作仍有若干明确不足。首先，视觉编码器实验目前仍处于第一阶段筛选，尚未在更贴近最终部署结构的训练中完成 fully-tuned 的最终对照；因此本文对 DINOv2-Small 的结论更适合表述为“具备进入下一阶段验证的潜力”，而不是“部署最优编码器”。其次，真机实验中单目标导航、探索模式与多目标任务的规模仍然有限，论文正文对此采用了显式占位说明，相关正式统计表、现场照片与失败案例分析仍需后续实验补齐。再次，当前离线指标（Forward Progress、Lateral Abs、Smoothness 等）主要服务于轨迹分布分析\cite{anderson2018evaluation}，尚未与真机任务成功率、姿态稳定性等更高层指标建立严格定量映射。最后，本文的 topomap 采集仍主要依赖人工沿路径采样\cite{savinov2018sptm,chaplot2020nts}，在长距离、复杂场景和动态环境中其覆盖密度与节点筛选策略仍有较大优化空间。

\section{未来展望}

基于当前研究所形成的系统底座，本文认为后续工作可以从以下几个方向继续展开。

\begin{enumerate}
    \item \textbf{视觉编码器的第二阶段最终部署训练}：在第一阶段筛选出 DINOv2-Small 等候选之后，进一步在贴近最终部署结构的训练链路中进行 fully-tuned 对照实验，并结合 MuJoCo 与真机闭环结果给出最终部署推荐，闭合本文两阶段研究路径。
    \item \textbf{更系统的真机统计实验}：在真机端补齐不同地图、不同重复次数、不同难度场景下的成功率与步数统计，并引入失败案例标注与恢复率指标\cite{anderson2018evaluation}，使真机章节具备与仿真章节对等的证据密度。
    \item \textbf{视觉记忆与拓扑增强}：探索在线构建或自更新 topomap 的机制，使系统能够在部署阶段根据真实环境变化动态调整候选节点集合，减轻人工采集负担，并与已有拓扑导航方法\cite{savinov2018sptm,chaplot2020nts,shah2021ving}形成对比。
    \item \textbf{跨平台扩展与 Tron1 等平台验证}：将当前统一推理模块与状态机架构扩展到更多足式与轮足平台，验证高层生成式策略在不同动力学约束下的可迁移性，并进一步检验本文“高层输出局部轨迹、中层吸收平台差异”的分层思想。
    \item \textbf{引入语言目标与多模态条件}：在 image-goal 基础上进一步引入语言描述条件，使系统能够接受“去那张图对应的位置”与“到走廊尽头左转”两类目标表达，推动视觉目标导航向多模态任务指令扩展。
    \item \textbf{长期运行与鲁棒性研究}：围绕相机噪声、通讯时延、地面打滑、局部遮挡等真实扰动，系统评估整套闭环在长时间运行中的鲁棒性与恢复能力，为扩散策略进入真实工程部署提供更充分的证据。
\end{enumerate}

总体而言，本文已经把原本主要面向轮式平台的 NoMaD 高层视觉导航策略，完整整理并扩展到 Lite3 四足平台，形成了一套算法、系统与平台相互支撑的研究闭环。未来若能沿上述方向继续推进，尤其是在第二阶段视觉编码器训练、真机统计实验与跨平台扩展上形成更充分的证据，基于动作扩散策略的足式视觉目标导航与探索，将有希望真正从研究原型走向可持续落地的通用导航方案。
