# 毕业答辩准备总览

题目：基于动作扩散策略的四足机器人视觉目标导航

## 一句话主线（必须背熟）

本文以 NoMaD 为高层视觉导航核心，围绕边缘推理效率、四足平台闭环控制和真实部署安全性，构建了统一推理模块、分层闭环系统和 Orin-Lite3 真机验证流程。

主线展开时要扣三组关键词：
- 算法层：动作扩散策略 / DDIM / CFG / TTS / 视觉编码器
- 系统层：分层架构 / 状态机 / 中层映射 / UDP 桥接
- 平台层：MuJoCo 仿真 / Jetson Orin / Lite3 / 真实拓扑地图

不要把答辩讲成"复现一个模型"或"写了很多脚本"。

## 三点核心贡献（顺序固定，背下来）

1. 统一视觉目标导航推理模块。将 DDIM、CFG、TTS 和视觉编码器替换纳入同一接口，确定默认配置为 EfficientNet-B0 + DDIM-2 + CFG=0 + TTS-8，相对基线 DDPM 在离线获得约 4.84 倍推理加速。

2. 面向 Lite3 的分层闭环系统。推理层、任务组织层、中层控制层、平台执行层四层解耦，使高层算法迭代与底层通信协议互不干扰，并支持 MuJoCo 与真机双后端复用。

3. Orin-Lite3 真机验证流程。多场景目标导航中四组配置均完成任务，最快方案闭环频率 6.80 Hz，相比基线 DDPM 的 2.89 Hz 提升约 2.35 倍，与离线实验的频率排序一致。

## 答辩心态提示

老师追问通常是因为对内容感兴趣或想确认你理解到位，而不是要为难你。回答时三步走：

1. 先承认或先肯定老师指出的现象（如"是的，确实如此"）。
2. 再用一句话解释原因，扣回本文的设计选择或局限。
3. 最后补一句后续改进方向，体现你知道边界在哪里。

最忌讳两种极端：
- 一是过度防御（"我做的没问题"），让老师觉得你没听懂或不接受批评。
- 二是过度自责（"我做得不好"），主动放大自己的不足。

保持平静、扣题、给数据，绝大多数问题都能稳住。
