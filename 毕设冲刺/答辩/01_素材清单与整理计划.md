# 答辩素材清单与整理计划

本文档把可用于答辩 PPT 的文字、表格、图片、视频和拓扑地图分类整理，并对每项素材标注答辩讲法。做 PPT 前应先读完本份。

## 0. 素材使用总原则

- 每页 PPT 只放一个核心结论，图表优先于大段文字。
- 数字一律先讲含义再讲数值（例如"DDIM-2 相对 DDPM 加速 4.84 倍"，不是"4.84 倍加速"）。
- 引用论文表格时只截关键列，避免把完整列名搬上 PPT。
- 视频不超过 20 秒，最好播放时配 1-2 句口头解读，不能让视频"自己说话"。

> 本文不是单纯验证一个视觉导航模型，而是面向四足机器人真实部署，解决动作扩散视觉目标导航的实时推理、系统闭环和真机安全执行问题。

### 真机结果表 PPT 标准写法

| 配置 | 成功率 | 闭环频率 | 一句话讲法 |
|---|---:|---:|---|
| 基线 DDPM | 100% | 2.89 Hz | 原始 NoMaD 配置，能跑但慢 |
| DDIM-2 + CFG=0 + TTS-8 | 100% | 6.80 Hz | 默认推荐方案，频率最高 |
| DDIM-2 + CFG=2 + TTS-8 | 100% | 3.43 Hz | 目标牵引增强，频率下降是 CFG 代价 |
| DDIM-3 + CFG=0 + 无 TTS | 100% | 5.90 Hz | 步数+1 步、关闭 TTS 的对照组 |

注意：答辩口头建议把 `DDIM-2 + CFG=2 + TTS-8` 称为"目标牵引增强方案"，不要过度强调"最优方案"，否则老师可能追问"为什么频率更低还叫最优"。

频率排序的一句话总结：

> 真机频率从快到慢分别是 DDIM-2、DDIM-3、CFG-2 增强、DDPM 基线，排序与离线实验完全一致，说明算法层结论在真实平台上得到了再次验证。

## 4. 视频素材

视频建议准备两类：一类是 PPT 内嵌短视频，一类是答辩现场备用原始视频。

### 推荐内嵌视频

| 视频 | 路径 | 建议用途 | 答辩配音 |
|---|---|---|---|
| 总剪辑 | `毕设冲刺/video/1-jianji.mp4` | 开场或结果页播放 15-25 秒 | "这段视频是真机多场景任务的合集" |
| 室内成功案例 | `毕设冲刺/video/走廊成功/.../navigation_record.mp4` | 真机结果页 | "室内走廊场景下的目标导航过程" |
| 最快方案案例 | `毕设冲刺/video/ddim2cfg0tts8/.../navigation_record.mp4` | 对应 6.80 Hz 配置 | "DDIM-2 + CFG=0 + TTS-8 配置实测 6.80 Hz" |
| 后方走廊成功案例 | `毕设冲刺/video/0428下午最优方案，后方走廊。成功/.../navigation_record.mp4` | 展示真实走廊任务 | "实验室外侧走廊的实际运行" |
| 室外斜坡案例 | `毕设冲刺/video/二号楼楼下斜坡1/.../navigation_record.mp4` | 室外零样本压力测试成功例 | "室外简单斜坡场景仍能维持基本闭环" |
| 室外失败案例 | `毕设冲刺/video/电草，失败/.../navigation_record.mp4` | 备份页，用于回答室外泛化边界 | "草坪等复杂场景出现失败，是分布外现象" |

### 视频使用注意

1. PPT 中最多内嵌 1-2 段视频，每段控制在 10-20 秒。
2. 视频要提前转成常见编码（推荐 H.264 mp4），避免答辩电脑无法播放。
3. 文件名含"失败"的素材不一定与日志状态完全一致，正式使用前要人工看一遍，不要只看文件夹名。
4. 视频页要配一句结论，例如"机器人能够沿真实拓扑地图推进，闭环频率主要受扩散采样步数影响"。
5. 现场播放前先确认音量为静音或合适音量，避免突然有提示音。
6. PPT 备份方案：若视频内嵌失效，立即切到"视频截图三联图"代替，不要在现场调试播放器。

PPT 可以把一组节点拼成"起点-中间-终点"的三图形式，解释滑动窗口导航：不是一次性追终点图，而是每个周期选取更近的实时子目标。

讲法示例：

> 这是后方走廊采集的拓扑地图，左边是起点节点 0，中间是节点 10，右边是终点节点 19。运行时，机器人不是直接对比当前图像和终点图，而是在当前位置附近的 ±4 个节点窗口内选择最近的下一节点作为子目标。

## 6. 备份材料

答辩当天建议带上：

1. PPT 源文件和 PDF 版本（分别保存）。
2. 论文 PDF：`论文/main.pdf`。
3. 关键视频的单独文件夹，避免 PPT 内嵌失效。
4. 关键表格截图或 Excel 备份。
5. 系统架构图、真机双链路图、拓扑地图图像各一张高清版本。
6. U 盘 + 云盘双备份，最好云盘可以离线下载到手机。
7. 代码仓库可以不主动展示，但如果老师追问实现链路，可以指出 UDP 桥接、状态机、导航主机和推理模块是分层组织的。

## 7. 关键素材自检表

在 PPT 完成后，按以下清单自检一遍：

- [ ] 真机结果表四行配置和闭环频率数字与第四章一致。
- [ ] DDIM-2 加速比 4.84× 出现在 PPT 上。
- [ ] 默认配置 EfficientNet-B0 + DDIM-2 + CFG=0 + TTS-8 完整出现。
- [ ] 分层系统图四层（推理 / 任务组织 / 中层控制 / 平台执行）完整。
- [ ] 真机双链路图横向纵向两条线都标注清楚。
- [ ] 视频在答辩电脑测试播放成功。
- [ ] 室外场景明确标注为"压力测试"或"分布外验证"，不是常规结果。
- [ ] 限速参数 0.12 m/s / 0.35 rad/s 至少在系统架构页出现一次（或在被问时说得出）。
