# 答辩现场检查清单

本清单按时间倒计时组织。每一项都建议打钩确认，不要凭印象判断"应该没问题"。

## 答辩前 7 天

技术准备：

- [ ] PPT 初稿完成，控制在 10-14 页。
- [ ] 每一页只讲一个核心结论。
- [ ] 所有图表替换为高清版本，优先用论文已有图片。
- [ ] 真机视频能在本机和另一台电脑上播放（H.264 mp4 编码）。
- [ ] 完整版（8-10 分钟）、5 分钟版和 3 分钟版答辩稿都已准备。
- [ ] 关键数字（4.84×、6.80 Hz、2.89 Hz、0.12 m/s）能脱稿说出。

问答准备：

- [ ] 八个最容易追问的问题逐条练习（详见本文末"最易翻车 8 问"）。
- [ ] 备份页准备：NoMaD 结构、DDIM/CFG/TTS 原理、滑动窗口、Orin 调试表、真机结果表、研究不足。

## 答辩前 3 天

练习：

- [ ] 按真实答辩时间完整讲 3 遍，每次计时。
- [ ] 删除超时页或超时句子。
- [ ] 视频剪到 10-20 秒，避免现场拖进度。
- [ ] 找一位同学或朋友模拟答辩，让其随机提问。

文件准备：

- [ ] PPT 另存为 PDF，防止格式错乱。
- [ ] 关键视频单独放到一个文件夹，不只依赖 PPT 内嵌。
- [ ] 备份页准备完成。

## 答辩前 1 天

文档自检：

- [ ] PPT 首页题目、姓名、学号、指导教师无错字。
- [ ] 所有图片清晰、无缺图。
- [ ] 视频路径正确、能播放。
- [ ] PPT 页码和讲稿页码对应。
- [ ] 论文 PDF 目录、摘要、实验表格可快速定位。

材料复制：

- [ ] U 盘和云盘双备份，包含：
  - PPT 源文件（pptx）
  - PPT PDF
  - `论文/main.pdf`
  - 答辩稿
  - 问题库
  - 关键视频文件夹
  - 备份页 PDF

休息与心态：

- [ ] 晚上 23 点前睡觉，不要熬夜改 PPT。
- [ ] 第二天的衣服、答辩证件、U 盘提前准备好。

## 答辩当天

到场前：

- [ ] 提前 30 分钟到场。
- [ ] 检查投影比例、字体、视频播放、音量。
- [ ] 关闭无关弹窗和通知（微信、邮件、IDE）。
- [ ] 桌面只保留 PPT、PDF、视频文件夹。

答辩前 5 分钟：

- [ ] PPT 放映前确认视频页能跳转和播放。
- [ ] 准备一瓶水放在讲台上。
- [ ] 深呼吸 3 次，告诉自己"主线一句话 + 三点贡献"。

答辩中：

- [ ] 开场 30 秒直接进入主题。
- [ ] 每页结尾落一句结论。
- [ ] 视频播放时暂停讲解，让画面说话。
- [ ] 关注评委表情，调整语速。
- [ ] 视频无法播放时立即切换到视频截图页，不在现场排查编码问题。

提问环节：

- [ ] 听完整个问题再回答，不要抢答。
- [ ] 不确定时可以说"老师我理解您的意思是……"复述一遍。
- [ ] 答完一题后给评委 1 秒反应时间，再准备下一题。

## 现场讲述策略

### 开头 30 秒

直接说明研究对象、问题和路线。不要从过长背景开始。

> 各位老师好，我的毕业设计题目是《基于动作扩散策略的四足机器人视觉目标导航》。本文研究如何把动作扩散视觉导航模型部署到 Lite3 四足机器人上，形成可实时推理、可仿真验证、可真机执行的闭环系统。

### 中间 6-8 分钟

按"问题 → 方法 → 系统 → 实验 → 结论"讲。每页结尾都要落到一句结论。

时间分配检查点：

| 时间点 | 应讲到的页 |
|---|---|
| 1.5 min | 完成 P3 问题页 |
| 3.0 min | 完成 P5 NoMaD 模块 |
| 4.5 min | 完成 P7 离线实验 |
| 6.0 min | 完成 P9 MuJoCo 仿真 |
| 7.5 min | 完成 P12 真机结果 |
| 8.0 min | 完成 P14 总结 |

如果时间偏快，在 P12 真机结果页多讲一组场景。
如果时间偏慢，跳过 P13 探索页，直接到总结。

### 结尾 30 秒

总结三点贡献和三点不足。主动承认不足反而更稳。

> 我的汇报到此结束。本文有三点贡献：统一推理模块、分层闭环系统、Orin-Lite3 真机验证流程；也有三点不足：真机规模有限、室外泛化不足、拓扑地图依赖预采集。后续将从真实数据重训、扩大真机统计、迁移多平台和引入语言目标四方面继续。请各位老师批评指正，谢谢。

## 回答问题策略

先给结论，再解释原因，最后补一句后续改进。

示例 1：

老师问：为什么 100% 成功率还说实验规模有限？

回答：

> 是的，本文的 100% 成功率是在当前真实场景规模和保守速度限幅下得到的，说明系统链路已经可运行并且具有一定鲁棒性，但还不能代表复杂场景下的充分统计结论。后续需要扩大场景和重复次数，补充置信区间、失败模式和轨迹误差统计。

示例 2：

老师问：DDIM 是已有方法，你的贡献在哪？

回答：

> 您说得对，DDIM 是 Song 等人 2020 年提出的，本文不主张 DDIM 是原创。本文的贡献在于"在 NoMaD 这类扩散导航策略上系统化评估 DDIM 加速的边界"——给出 DDIM-1 到 DDIM-10 的完整 Pareto 前沿、与四个编码器的鲁棒性验证、以及真机实测频率。这些数据在原 NoMaD 工作中并不存在。后续可以扩展到更多扩散变体的对比。

## 突发情况预案

### 视频播放失败

- 立即切到对应的视频截图页（应提前准备）。
- 不要尝试在现场调试播放器。
- 一句话过渡：这部分视频提前准备了截图，可以看到机器人沿走廊推进的过程。

### 笔记本断电 / 投影中断

- 主动征求几秒钟时间，让组织老师协调。
- 如果时间紧张，可以用 PDF 版本在另一台机器继续。
- 不要慌张，组织方会理解。

### 时间被压缩到 5 分钟

- 跳过 P2 背景页、P6 推理优化页、P13 室外页。
- 重点保留：P1 题目、P3 问题、P5 NoMaD、P7 离线、P10 真机双链路、P12 真机结果、P14 总结。

### 老师追问超出准备范围

- 先承认：这是个好问题。
- 再说边界：本文这部分确实没有重点研究。
- 给方向：如果要解决，应该从 ×× 方向入手。
- 不要硬装懂。

## 备份页建议

备份页不一定讲，但要准备：

1. DDPM 与 DDIM 对比公式简化图。
2. CFG 条件 / 无条件分支示意。
3. TTS 候选筛选示意。
4. 滑动窗口拓扑地图示意。
5. Orin 阶段一调试表（模型加载 2.87 s、视觉编码 56.9 ms、扩散采样 86.7 ms、端到端 143.6 ms）。
6. 多场景真机实验表（四组配置成功率与频率）。
7. 编码器对比详细表。
8. 研究不足与未来工作。

切到备份页的话术：

> 这个问题我准备了一张备份页，可能更直观，我切到第 X 页。

## 心态调整

答辩 8 分钟，但准备了 4 个月。

老师追问通常是因为对你的工作感兴趣，而不是要为难你。回答得不完美也没关系，关键是表现出你理解自己的工作边界、知道未来怎么改进。

最后一个建议：答辩前 1 小时不要再改 PPT，把时间花在喝水、上厕所、调整呼吸上。技术准备到此为止，剩下的就交给你这几个月的积累。

祝答辩顺利。
