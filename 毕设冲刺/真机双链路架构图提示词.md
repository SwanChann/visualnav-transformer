# 真机双链路架构图 GPT 图像生成提示词

## 用途

用于生成论文第五章“真机系统双链路设计”的架构示意图。图像需要表达两条链路：

1. 横向实时推理链路：从相机图像到 twist 指令。
2. 纵向分层控制链路：从高层 NoMaD 到中层状态机/PD，再到底层 UDP 桥接和 Lite3 运控。

## 推荐提示词

请生成一张学术论文风格的系统架构图，主题为“Orin + Lite3 真机视觉导航双链路系统”。画面采用干净的白底或浅灰底，矢量信息图风格，线条清晰，适合放入本科毕业论文。整体布局分为横向链路和纵向链路，两条链路在中间交叉汇合。

横向链路从左到右排列，标题为“横向实时推理链路：图像到 twist 指令”。依次绘制以下模块，并用箭头连接：

- Orin Camera / Real-time FPV Images
- Image Preprocessing / Context Buffer
- Visual Encoder
- Distance Predictor
- Diffusion Policy
- PD Mapping
- Twist Command

在 Visual Encoder 模块旁边标注：input = current frame + previous 3 frames + real-time subgoal image。在 Distance Predictor 模块旁边标注：local topomap window, closest node estimation。在 Diffusion Policy 模块旁边标注：generate local waypoints。在 PD Mapping 模块旁边标注：waypoint to vx, vy, wz。

纵向链路从上到下排列，标题为“纵向分层控制链路：NoMaD 到 Lite3 运控”。依次绘制以下层级，并用向下箭头连接：

- High-level NoMaD Host on Jetson Orin
- Mission Queue / Topomap Manager / State Machine
- Middle-level PD Control and Safety Limits
- UDP Bridge / Heartbeat / Twist Refresh
- Lite3 Motion Controller
- Lite3 Robot Locomotion

请在图中体现 topomap 的作用：在 Visual Encoder 和 Distance Predictor 附近绘制一条由小图片节点组成的 topomap sequence，标注为 Real Topomap: I0, I1, ..., Ig。用一个半透明滑动窗口框住其中一段节点，标注 sliding window。用高亮颜色标出 selected subgoal node，并用箭头指向 Visual Encoder 或 Diffusion Policy，表示当前扩散模型使用的不是最终终点图，而是实时子目标图。

请在底部或右侧加入简洁说明框：

- Horizontal path handles real-time perception and action generation.
- Vertical path handles software layering, command delivery, and robot safety.
- The bridge repeats the latest limited twist command between NoMaD inference steps.

视觉风格要求：

- 使用蓝色表示感知与视觉编码模块。
- 使用绿色表示 topomap 和距离预测模块。
- 使用紫色表示扩散策略模块。
- 使用橙色表示 PD 控制和 twist 指令。
- 使用红色或深灰表示安全、心跳、急停和 Lite3 底层运控。
- 不要使用复杂背景，不要使用照片质感，不要使用卡通机器人。
- 图中文字要清晰、简短、适合论文插图。
- 保持横向链路和纵向链路都清楚可读，不要让箭头交叉过多。

## 中文版提示词

请生成一张学术论文风格的系统架构图，标题为“Orin + Lite3 真机视觉导航双链路系统”。图中必须同时体现两条链路：

第一条是横向实时推理链路，从左到右依次为：实时相机图像、图像预处理与四帧上下文缓存、视觉编码器、距离预测器、扩散策略模型、PD 映射、twist 速度指令。标注视觉编码器输入为“当前帧 + 前三帧 + 实时子目标图像”；标注距离预测器在 topomap 滑动窗口内估计 closest node；标注扩散策略生成局部 waypoint；标注 PD 映射将 waypoint 转为 vx、vy、wz。

第二条是纵向分层控制链路，从上到下依次为：Jetson Orin 上的高层 NoMaD 导航主机、任务队列与 topomap 管理、状态机、中层 PD 控制与速度限幅、UDP 桥接与心跳、Lite3 运动主机、Lite3 机器人步态执行。

在图中央绘制一条由多个小图像节点组成的真实 topomap 序列，标出 I0、I1、...、Ig。用半透明框表示 sliding window，用高亮节点表示 selected subgoal。请明确表现 selected subgoal 会输入扩散策略，而最终 goal 只作为任务终点上界，不是每一帧直接追踪的目标图。

整体风格要求白底、矢量图、论文插图、清晰箭头、模块边框统一、文字简短。颜色建议：蓝色表示视觉编码，绿色表示 topomap 与距离预测，紫色表示扩散策略，橙色表示 PD 与 twist 指令，深灰或红色表示 UDP、心跳、安全和底层运控。不要画成科幻风，不要加入复杂背景，不要使用卡通风格。
