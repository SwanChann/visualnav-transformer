## 一、课题研究目的和意义

### 1.1 研究背景

随着具身智能(Embodied AI)技术的快速发展，机器人在日常生活场景中的自主导航能力成为研究热点。传统导航系统依赖于同步定位与建图(SLAM)技术，需要精确的几何地图和昂贵的传感器配置。然而，这类方法在面对动态、未知环境时往往表现欠佳，且难以快速适应新场景。

近年来，**视觉导航(Visual Navigation)** 作为一种端到端的学习范式受到广泛关注。这类方法直接从视觉输入学习导航策略，具有更好的泛化能力和更低的部署成本。特别是基于深度学习的方法，能够从大规模数据中学习丰富的视觉特征和导航经验。

在此背景下，**扩散模型(Diffusion Models)** 作为新一代生成模型，展现出强大的多模态分布建模能力。将扩散模型应用于机器人策略学习——即**扩散策略(Diffusion Policy)**——已成为具身智能领域的前沿方向。

### 1.2 国内外研究现状综述

#### 1.2.1 视觉导航领域

视觉导航是指机器人仅依靠视觉传感器完成导航任务的技术。根据任务形式可分为：

| 任务类型 | 描述 | 代表工作 |
|---------|------|---------|
| **点目标导航(PointNav)** | 导航到指定坐标位置 | DD-PPO (Wijmans et al., 2019) |
| **图像目标导航(ImageNav)** | 导航到目标图像所示位置 | ViNG (Shah et al., 2021), NRNS (Hahn et al., 2021) |
| **物体目标导航(ObjectNav)** | 导航到指定类别的物体 | ZSON (Majumdar et al., 2022) |
| **视觉语言导航(VLN)** | 根据自然语言指令导航 | VLN-BERT (Hong et al., 2020) |

本课题聚焦于**图像目标导航(ImageNav)**，即给定目标图像，机器人需导航至该目标位置。该任务不依赖语义标签或精确坐标，更接近人类的视觉导航方式。

#### 1.2.2 扩散模型与机器人策略学习

扩散模型通过逐步去噪过程生成数据，相比传统生成模型(如VAE、GAN)具有以下优势：

- **训练稳定性**：避免了GAN的模式崩塌问题
- **分布覆盖**：能够更好地覆盖多模态分布
- **生成质量**：在图像生成任务中达到SOTA水平

**扩散策略(Diffusion Policy)** 将扩散模型应用于机器人动作生成：

| 研究方向 | 代表工作 | 核心贡献 |
|---------|---------|---------|
| **机械臂操作** | Diffusion Policy (Chi et al., 2023) | 首次将DDPM应用于模仿学习 |
| **视觉导航** | NoMaD (Sridhar et al., 2023) | 统一导航与探索的扩散策略 |
| **运动控制** | DiffusionRL (Wang et al., 2023) | 扩散模型用于强化学习策略 |

#### 1.2.3 足式机器人导航

足式机器人(四足、双足)相比轮式机器人具有更强的地形适应能力，但导航控制更为复杂：

**现有研究方向**：
- **经典控制方法**：MPC、ZMP平衡控制
- **强化学习方法**：ANYmal locomotion (Lee et al., 2020)
- **模仿学习方法**：Legged Locomotion from Observation

**核心挑战**：
1. 平衡控制与导航规划的耦合
2. 复杂地形适应
3. 不同机器人平台的泛化

#### 1.2.4 NoMaD框架分析

NoMaD (Goal Masked Diffusion Policies for Navigation and Exploration) 是本课题的核心参考框架，其主要创新包括：

**1. 统一的导航与探索策略**
- 通过Goal Masking机制实现导航与探索的统一
- 训练时50%概率遮蔽目标图像
- 推理时通过mask控制行为模式

**2. 扩散策略生成轨迹**
- 使用DDPM生成waypoint轨迹而非直接速度
- 10步扩散迭代实现高质量生成
- 多样本采样增强鲁棒性

**3. 与MPC的联系（本课题创新视角）**
NoMaD每次生成8个waypoint，选择其中一个执行后重新规划，这与**模型预测控制(MPC)** 具有高度相似性：

| 特征 | MPC控制器 | NoMaD扩散策略 |
|------|----------|---------------|
| 预测时域 | 预测N步控制序列 | 生成8个waypoint轨迹 |
| 执行策略 | 只执行第一个控制量 | 选择第k个waypoint执行 |
| 滚动优化 | 每步重新优化 | 每步重新扩散生成 |
| 约束处理 | 显式约束优化 | 数据驱动隐式学习 |

**关键洞察**：NoMaD的"生成-选择-执行-重规划"循环本质上实现了**隐式MPC**，将传统MPC的显式优化替换为扩散模型的生成过程。这一视角为足式机器人的平衡控制与导航规划耦合提供了新思路。

### 1.3 研究意义

#### 1.3.1 理论意义

1. **统一框架的构建**：探索扩散策略在足式机器人导航中的应用，建立从视觉输入到抽象动作空间的端到端映射
2. **跨平台泛化机制**：研究通过抽象动作空间实现不同足式机器人平台间的策略迁移
3. **隐式MPC理论**：从MPC角度解释扩散策略，为理解和改进该方法提供新视角

#### 1.3.2 应用意义

1. **降低部署门槛**：无需为特定机器人和环境单独训练，提高机器人产品的快速部署能力
2. **增强适应性**：在未知、动态日常场景中实现自主导航和探索
3. **推动产业发展**：为服务机器人、物流机器人等应用提供技术支撑

## 二、课题研究内容

### 2.1 研究内容概述

本课题旨在研究并实现一种**基于动作扩散策略的通用导航与探索框架**，使四足和双足机器人能够在日常使用场景中，无需或仅需少量特定数据即可完成多样化的导航任务。

### 2.2 具体研究内容

#### 2.2.1 NoMaD核心框架复现

**目标**：在仿真环境中完整复现NoMaD框架

**具体任务**：

1. **视觉编码器复现**
   - EfficientNet-B0骨干网络
   - 多头自注意力时序融合模块
   - Goal Masking机制实现
   
   ```python
   # 核心架构
   NoMaD_ViNT:
   ├── EfficientNet-B0 (观察编码器)
   ├── EfficientNet-B0 (目标编码器, 6通道输入)
   ├── PositionalEncoding
   └── TransformerEncoder (4层, 4头注意力)
   ```

2. **扩散策略网络复现**
   - Conditional UNet1D网络结构
   - DDPM调度器配置
   - 噪声预测与去噪过程
   
   ```python
   # 扩散配置
   DDPMScheduler:
     num_train_timesteps: 10
     beta_schedule: 'squaredcos_cap_v2'
     prediction_type: 'epsilon'
   ```

3. **距离预测模块复现**
   - 3层MLP网络
   - 用于子目标选择

#### 2.2.2 抽象动作空间设计

**目标**：设计适用于足式机器人的抽象动作表示

**核心思想**：NoMaD输出的是相对坐标系下的waypoint轨迹，而非直接的关节命令。这种抽象表示天然适合跨平台泛化。

**动作空间定义**：
```
Action Space: [8, 2] 或 [8, 4]
├── dx: 前向位移 (相对于机器人坐标系)
├── dy: 侧向位移 (相对于机器人坐标系)
├── sin(Δyaw): 航向变化正弦值 (可选)
└── cos(Δyaw): 航向变化余弦值 (可选)
```

**平台适配层设计**：
```
Waypoint → Platform Adapter → 底层控制
          ├── 四足机器人: waypoint → 步态控制器
          ├── 双足机器人: waypoint → 平衡控制器
          └── 轮式机器人: waypoint → PD控制器 (参考)
```

#### 2.2.3 足式机器人特性优化

**1. 平衡控制集成**

足式机器人需要同时维持平衡和执行导航，拟采用分层控制架构：

```
高层策略 (NoMaD扩散策略)
    ↓ waypoint轨迹
中层规划 (步态生成)
    ↓ 足端轨迹
底层控制 (关节PD控制/力矩控制)
    ↓ 关节命令
```

**2. 地形适应能力**

- 研究在waypoint生成时隐式考虑地形信息
- 探索通过数据增强提升地形适应能力

**3. MPC视角的改进**

基于NoMaD与MPC的类比，探索以下改进方向：
- **可变预测时域**：根据场景复杂度动态调整生成的waypoint数量
- **约束感知生成**：在扩散过程中引入可行性约束
- **执行索引优化**：自适应选择最优执行waypoint

#### 2.2.4 仿真实验与验证

**仿真平台选择**：
- **Habitat/Gibson**：室内场景导航
- **Isaac Sim/Gym**：足式机器人物理仿真
- **PyBullet**：轻量级验证

**实验设计**：

| 实验类型 | 评估指标 | 对比基线 |
|---------|---------|---------|
| 目标导向导航 | 成功率、SPL、碰撞率 | ViNT, DD-PPO |
| 自主探索 | 覆盖率、探索效率 | Frontier-based |
| 跨平台泛化 | 零样本迁移成功率 | 专用训练策略 |

#### 3.2.2 第二阶段：足式机器人适配

**Step 1: 仿真环境搭建**

选择NVIDIA Isaac Sim作为主要仿真平台：

**Step 2: 抽象动作空间与适配器设计**

```python
class FootedRobotAdapter:
    """将waypoint转换为足式机器人控制命令"""
    
    def __init__(self, robot_type: str):
        self.robot_type = robot_type
        self.gait_controller = self._init_gait_controller()
        
    def waypoint_to_command(self, waypoint: np.ndarray):
        """
        输入: waypoint [dx, dy] 或 [dx, dy, sin, cos]
        输出: 底层控制命令
        """
        # 提取目标速度方向
        target_velocity = self._compute_target_velocity(waypoint)
        
        # 调用步态控制器
        joint_commands = self.gait_controller.step(target_velocity)
        
        return joint_commands
```

#### 3.2.3 第三阶段：MPC视角优化与验证

**MPC-Diffusion对应关系**

| MPC组件 | 扩散策略对应 | 优化方向 |
|--------|-------------|---------|
| 预测模型 | 扩散生成模型 | 提高生成质量 |
| 代价函数 | 隐式学习 | 引入显式奖励引导 |
| 约束 | 数据隐式约束 | Classifier Guidance |
| 优化器 | 扩散采样 | 加速采样方法 |

**具体优化方法**

1. **Classifier-Free Guidance**
   ```python
   # 引导生成更目标导向的轨迹
   noise_pred = (1 + w) * cond_noise - w * uncond_noise
   ```

2. **可变扩散步数**
   ```python
   # 根据场景复杂度调整
   if simple_scene:
       num_steps = 5
   else:
       num_steps = 10
   ```

3. **执行索引自适应选择**
   ```python
   # 基于距离预测选择最优waypoint
   waypoint_idx = select_optimal_waypoint(distances, trajectory)
   ```
