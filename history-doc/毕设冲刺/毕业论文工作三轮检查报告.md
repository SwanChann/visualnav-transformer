## 二、实验设计是否完整、科学、统计

### 1. DDIM 实验

设计基本完整，具备统计性：

| 项 | 当前状态 |
|---|---|
| 配置 | `ddpm_10`、`ddim_10`、`ddim_5`、`ddim_3`、`ddim_2`、`ddim_1` |
| 测试集 | short / medium / long 三个 suite |
| 样本量 | 24 cases |
| 重复 | 每个 case 每配置 8 runs，每次 8 samples |
| 指标 | latency、MSE、diversity、path length、forward progress、lateral、smoothness |
| 统计 | mean、std、CI95 |

结论口径：

1. `ddim_1` 速度最快，但 MSE 和 diversity 明显异常，不推荐。
2. `ddim_5` 是稳健备选：14.18ms，2.01×，MSE 0.004776。
3. `ddim_2` 是部署实时性优先配置：5.96ms，4.79×，MSE 0.020992。

建议补充：

1. 在论文中说明 CI95 是对 24 个 case-level 均值计算，重复采样用于形成每个 case 的稳定估计。
2. 如果篇幅允许，增加 paired comparison 或 bootstrap CI，增强统计说服力。

### 2. CFG 实验

设计基本完整，具备统计性：

| 项 | 当前状态 |
|---|---|
| 引导强度 | -1.0、0.0、0.5、1.0、2.0、4.0 |
| 测试集 | short / medium / long |
| 样本量 | 24 cases |
| 重复 | 每个 case 每配置 8 runs |
| 指标 | latency、shift、diversity、forward progress、lateral、smoothness |

结论口径：

1. 从整体统计看，`w=0.0` 是默认配置，因为没有额外 CFG 推理开销。
2. `w=1.0` 可作为障碍场景增强配置，特别是 medium MuJoCo 结果中步数从 85 降到 61。
3. `w=4.0` shift 明显偏大，不宜作为默认。

## 五、最终建议写法

最终论文主线建议这样收束：

1. 第三章：NoMaD 基线复现与部署底座。已有数据集、基线、路径/环境检查可以支撑。
2. 第四章：部署导向优化。以 DDIM、CFG、DDIM×CFG 联合优化为核心，DINOv2 写成探索性增强。
3. 第五章：Lite3 四足 MuJoCo 联合导航为主要落地成果；Tron1 写成跨形态迁移接口与资产规范，除非后续补齐模型和结果。

最终推荐配置建议写为：

1. 默认部署：NoMaD + DDIM-2 + CFG `w=0.0`。
2. 障碍增强：NoMaD + DDIM-2 + CFG `w=1.0`。
3. 保守备选：NoMaD + DDIM-5，用于强调更低 MSE 的场合。

这套说法和现有统计结果、联合优化结果、Lite3 MuJoCo 结果是一致的。
