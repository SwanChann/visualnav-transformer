| 真机部署安全 | 相机、通信、状态机、急停和人工监护必须协同 |

60 秒讲法：

> 本文的核心问题是：如何把动作扩散视觉导航模型真正接到四足机器人上，并做到实时、安全、可复现。页面中三张卡片分别对应算法、系统和实验挑战。算法侧，扩散采样需要多步去噪，边缘设备压力较大；系统侧，NoMaD 输出局部轨迹，而 Lite3 接收速度指令；实验侧，仿真只能验证链路，真实走廊和室外光照才会暴露泛化边界。

### 第 5 页：视觉目标导航与 NoMaD 推理模块

核心结论：

NoMaD 负责把历史观察和目标图像转化为多条局部航点候选。

页面内容：

- 使用 `论文/figures/algo-overview-placeholder.png`
- 简化流程：历史观察 + 目标图像 → 视觉编码器 → 距离预测器 / 扩散策略头 → 候选航点

60 秒讲法：

> 本文的算法基线是 NoMaD。页面左侧显示它的输入输出：历史观测图像和目标图像进入视觉编码器，距离预测器用于判断拓扑节点远近，扩散策略头生成局部航点。右侧强调两个关键数字：模型约 19.05M 参数，默认一次生成 8 条候选动作。本文保留 NoMaD 的高层能力，重点优化推理速度、候选选择，并把局部动作适配到四足速度控制。

过渡：40 ms 在边缘设备上仍偏慢，本文从四个角度优化推理。

### 第 6 页：推理优化 / DDIM、CFG、TTS、编码器

核心结论：

四类优化分别作用在不同层级，最终形成统一推理模块。

页面内容（四模块卡片）：

| 方法 | 作用 | 一句话定位 |
|---|---|---|
| DDIM | 减少去噪步数 | 主要解决速度问题 |
| CFG | 增强目标条件 | 可调增强项，默认不打开 |
| TTS | 多候选筛选 | 低成本改善候选选择 |
| 编码器替换 | 改变视觉表征 | 建立可替换、可评测框架 |

60 秒讲法：

> 这一页把四类改进放到统一推理模块周围。DDIM 主要解决速度问题，用少步确定性采样替代多步随机采样；CFG 调整目标图像的引导强度，但会增加一次条件分支开销；TTS 一次生成多条轨迹，再用距离预测器筛选；编码器替换用于比较不同视觉表征。最终进入真机的默认组合是 EfficientNet-B0、DDIM-2、CFG=0、TTS-8。

过渡：下面看离线实验的结论。

### 第 7 页：离线实验结果

核心结论：

DDIM-2 是最适合进入闭环的默认加速配置；TTS-8 以低成本改善候选筛选；CFG 默认开启收益不足。

页面内容：

- 放 `论文/figures/ddim_comparison.png`
- 配关键数据小表：

| 配置 | 时延 | 加速比 | 备注 |
|---|---:|---:|---|
| DDPM-10 基线 | 40 ms | 1.00× | NoMaD 默认 |
| DDIM-2 | 8.3 ms | 4.84× | 默认推荐 |
| DDIM-1 | 4.5 ms | 8.87× | MSE 急剧上升，不可用 |

- 底部一行：默认配置 EfficientNet-B0 + DDIM-2 + CFG=0 + TTS-8

60 秒讲法：

> 离线消融主要回答“默认配置怎么选”。页面上方两张图分别展示 DDIM 加速和 DDIM/CFG/TTS 的时延-进展权衡。DDIM-2 相比 DDPM-10 在纯采样上约 4.84 倍加速，把采样时间从 40 毫秒量级降到 8 毫秒量级；CFG 会带来近似双分支开销，真实平台收益不稳定；TTS-8 成本较低，能保留候选多样性。因此默认关闭 CFG，采用 DDIM-2 和 TTS-8。

过渡：算法准备好后，需要把它接入真实四足平台。

### 第 10 页：Orin-Lite3 真机双链路架构

核心结论：

真机系统由横向实时推理链路和纵向分层控制链路共同组成。

页面内容：

- 使用 `论文/figures/shuanglianlu.png`
- 左侧讲横向链路：相机图像 → 视觉编码 → 距离预测 → 扩散策略 → PD 映射 → twist 指令
- 右侧讲纵向链路：NoMaD 主机 → 状态机与 PD 控制 → UDP 桥接 → Lite3 运控
- 关键参数：高层推理约 6.8 Hz，UDP 速度刷新 25 Hz，心跳 5 Hz，最大线速度 0.12 m/s、角速度 0.35 rad/s

60 秒讲法：

> 真机部署采用 Orin 和 Lite3 的双链路结构。页面左侧是完整系统图，右侧拆成水平推理链和垂直控制链。水平链从相机图像进入 NoMaD，经过距离预测、扩散策略和 PD 映射得到速度指令；垂直链负责 UDP 桥接、Lite3 高层接口和底层步态稳定。为了安全，速度刷新设置为 25Hz，心跳 5Hz，最大线速度 0.12m/s，最大偏航 0.35rad/s。

### 第 12 页：真机实验结果

核心结论：

在当前真实场景规模和保守速度限幅下，系统完成多场景目标导航；DDIM-2 配置显著提高闭环频率。

页面内容：

放真机结果表和一张视频截图：

| 配置 | 成功率 | 闭环频率 |
|---|---:|---:|
| 基线 DDPM | 100% | 2.89 Hz |
| DDIM-2 + CFG=0 + TTS-8 | 100% | 6.80 Hz |
| DDIM-2 + CFG=2 + TTS-8 | 100% | 3.43 Hz |
| DDIM-3 + CFG=0 + 无 TTS | 100% | 5.90 Hz |

视频：

- 只放 10-20 秒
- 推荐 `毕设冲刺/video/ddim2cfg0tts8/.../navigation_record.mp4` 或总剪辑

60 秒讲法：

> 这一页是真机走廊结果。左侧表格和柱状图显示，四组配置在当前测试走廊中都完成到达。DDPM 基线高层频率为 2.89Hz，默认配置 DDIM-2、CFG=0、TTS=8 达到 6.80Hz，是最高频率；开启 CFG 后降到 3.43Hz，说明引导分支会明显增加开销。右侧视频用于展示默认配置下的真实导航过程，结论是成功率不变时，DDIM 显著提高闭环频率。

视频播放：现场停顿 10-15 秒，让视频说话，结束后接一句"机器人沿真实拓扑地图推进，闭环频率主要受扩散采样步数影响"。

### 第 13 页：探索与室外零样本压力测试

核心结论：

60 秒讲法：
