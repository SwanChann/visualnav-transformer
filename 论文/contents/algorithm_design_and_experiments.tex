\chapter{基于动作扩散策略的统一视觉目标导航推理模块}

\section{问题分析}

在视觉目标导航任务中，高层策略需要根据当前图像、历史观察和目标图像生成可执行的局部运动。若直接回归单一速度或单一路径，模型在走廊分叉、遮挡、目标不确定等场景中容易把多个合理动作平均为一条不合理轨迹。动作扩散策略为这一问题提供了新的实现方式：它不把导航决策看成单点回归，而是把未来航点序列看成条件生成结果，通过逐步去噪从多模态轨迹分布中采样可执行候选。因此，本章首先面对的问题不是完整系统如何部署，而是如何将动作扩散策略组织为可被后续系统复用的统一视觉目标导航推理模块，并对其推理质量与效率进行评价。

围绕这一问题，已有方法 NoMaD 将视觉编码、距离预测和动作扩散策略组织在同一导航模型中，使机器人能够在目标图像或拓扑地图条件下生成局部航点轨迹。但对本文而言，直接使用 NoMaD 还不够：一方面，需要先建立其基础推理链路，弄清视觉编码器、距离预测头、扩散策略头、视觉掩码（goal mask）与航点输出之间的关系，形成可对照的离线基线；另一方面，原始扩散采样存在迭代次数多、推理耗时高的问题，若后续部署到 Jetson Orin 等资源受限平台，必须进一步分析采样步数、条件引导、候选筛选和视觉编码器规模之间的取舍。

由此，本章的核心挑战可以概括为三点。第一是实现问题，即把视觉目标导航形式化为条件轨迹分布学习问题，并建立 NoMaD 从图像输入到航点输出的完整推理流程。第二是效率问题，即在不破坏轨迹质量的前提下，通过 DDIM、CFG、TTS 和视觉编码器替换等方法降低扩散推理开销或提升候选质量，使算法具备进入边缘平台闭环的可能。第三是解耦问题，即本章得到的算法配置不能停留在离线实验流程中，而应被整理为后续系统层可以封装调用的高层推理模块，使其输出与四足平台的中层控制和底层通信保持接口独立。

基于上述分析，本章按``任务定义—模型机制—基线实验—优化实验—消融分析—框架确定''组织内容。先定义视觉目标导航任务和航点表示，再说明 NoMaD 的扩散建模机制；随后在 GoStanford 数据集上建立基线推理结果，并围绕 DDIM 采样加速、CFG 条件引导、TTS 推理时搜索和视觉编码器升级开展对比实验；最后通过联合消融确定可进入第三章 MuJoCo 闭环验证和第四章 Lite3 真机部署的默认算法配置。

\section{视觉目标导航任务定义与航点表示}

\subsection{视觉目标导航任务定义}

机器人导航的目标是在给定观察、任务目标和运动约束的条件下，使机器人从当前状态移动到目标区域。一个完整导航系统通常涵盖环境感知、状态表示、目标表达、局部决策与运动执行五个环节\cite{thrun2005probabilistic,anderson2018evaluation}。在输出形式上，高层导航策略可以输出底层控制量、局部路径点或局部轨迹序列；本文让高层模型输出局部航点轨迹，再由中层控制器完成执行映射。

如果把高层策略写成函数形式，则有
\begin{equation}
\pi : (\mathcal{O}_t, g) \mapsto \mathbf{A}_t ,
\end{equation}
其中 $\mathcal{O}_t$ 表示时刻 $t$ 的图像观察或观察序列，$g$ 表示任务目标，$\mathbf{A}_t$ 表示未来短时间内的局部轨迹。该表示天然适合与不同平台解耦，也是本文能够将高层视觉导航从轮式框架迁移到 Lite3 四足平台的重要原因。

观察空间方面，本文统一使用 RGB 图像作为输入，并保留最近 $K+1$ 帧上下文 $\mathcal{O}_t = \{I_{t-K}, \ldots, I_t\}$。每个航点$\mathbf{a}_i = (\Delta x_i, \Delta y_i)$ 表示相对于机器人当前位姿的二维增量位移（$x$ 前向、$y$ 左侧），策略输出因此不依赖全局定位。执行上采用闭环模式：每个高层周期生成长度 $H=8$ 的航点序列，固定取第 $k=2$ 个航点作为本次控制周期的局部目标位移，由中层 PD 控制器映射为速度指令；下一周期再基于最新相机帧重新生成。这种``规划长 8 步、每周期只执行其中一个超前点''的策略与模型预测控制（MPC）一脉相承，扩散策略相当于把 MPC 的优化求解替换为条件扩散采样。

视觉导航以图像作为主要环境输入，并基于视觉信息完成导航决策\cite{zhu2017targetdriven,anderson2018evaluation}。目标导航则进一步关注目标的给出形式，常见类别包括：
\begin{itemize}
    \item \textbf{点目标（point-goal） 导航}\cite{ddppo2020}：目标以坐标点形式给出，要求机器人到达指定位置；
    \item \textbf{图像目标（image-goal） 导航}：目标以一张或多张图像给出，要求机器人到达图像所对应的位置；
    \item \textbf{物体目标（object-goal） 导航}：目标以物体类别给出（如``找到冰箱''），需要语义理解能力；
    \item \textbf{语言目标（language-goal） 导航}：目标以自然语言指令给出，是最灵活但也最具挑战的形式。
\end{itemize}
本文研究 image-goal 场景：相较于绝对坐标，图像目标更符合真实应用——用户更容易给出``到达目标图像对应的位置''，而非统一坐标系下的精确终点；相较 object-goal 与 language-goal，图像目标无需语义理解模块、表达歧义更低，能在无 GPS 与无预建地图的场景中直接工作。

本文关注的核心任务是：给定机器人当前视觉观察、短历史观察和目标图像，生成一段局部航点轨迹，并将其作为中层控制器的参考输入。沿用 NoMaD 的基本思想\cite{nomad2023}，本方法不直接预测单步速度命令，而是学习条件轨迹分布
\begin{equation}
p(\mathbf{A}_t \mid \mathcal{O}_t, I_g),
\end{equation}
其中 $p(\cdot)$ 表示条件概率分布，$\mathcal{O}_t$ 表示时刻 $t$ 的历史视觉观察，$I_g$ 表示当前控制周期使用的目标图像，在拓扑导航中是拓扑地图序列上``当前定位的下一节点''图像，$\mathbf{A}_t$ 表示未来局部航点序列。

从马尔可夫决策过程（Markov Decision Process, MDP）的视角来看，视觉导航可以被建模为一个元组 $\mathcal{M} = (\mathcal{S}, \mathcal{A}, T, R, \gamma)$，其中 $\mathcal{S}$ 表示状态空间（即视觉观察空间），$\mathcal{A}$ 表示动作空间，$T$ 表示转移概率，$R$ 表示奖励函数，$\gamma$ 表示折扣因子。在本文的框架中，策略 $\pi$ 不是直接在 MDP 上求解单步最优动作，而是学习一个条件轨迹分布 $p(\mathbf{A}_t \mid \mathcal{O}_t, I_g)$，这种分布式策略具有天然的多模态建模能力。

具体来说，条件轨迹分布与传统 MDP 策略之间的联系可通过以下关系理解：若将未来 $H$ 步动作序列视为一个联合决策变量，则条件轨迹分布相当于在扩展动作空间 $\mathcal{A}^H$ 上的策略。与逐步递推不同，这种联合建模能够在单次推理中捕获全局轨迹结构，避免了自回归策略中误差累积的问题。形式上：
\begin{equation}
p(\mathbf{A}_t \mid \mathcal{O}_t, I_g) = p(\mathbf{a}_1, \mathbf{a}_2, \ldots, \mathbf{a}_H \mid \mathcal{O}_t, I_g),
\end{equation}
其中 $p(\cdot)$ 表示条件概率分布，$H$ 表示未来预测步数，$\mathbf{a}_i$ 表示第 $i$ 个局部航点。每个 $\mathbf{a}_i$ 并非独立采样，而是通过扩散过程的联合去噪一次性生成。

这种建模方式与经典的行为克隆（Behavioral Cloning）策略存在本质区别。行为克隆通常将策略参数化为确定性映射 $\pi_\theta: \mathcal{O} \to \mathcal{A}$ 或简单的高斯分布，只能表达单峰的动作分布。而基于扩散模型的条件生成策略通过迭代去噪过程，能够从复杂的多模态分布中采样，天然适合处理导航任务中的分支决策场景。此外，扩散模型的训练目标（噪声预测损失）在数值上比最大似然目标更稳定，不容易出现模式坍塌（mode collapse）问题。

\subsection{拓扑导航与拓扑地图表示}

为了降低对精确几何地图的依赖，拓扑导航只保留若干代表性视觉节点及其连通关系\cite{savinov2018sptm,chaplot2020nts,shah2021ving}。本文系统中的拓扑地图不是部署时由编码器在线生成的图结构，而是人工沿目标路径预先采集的一段\textbf{有序}视觉节点序列，文件名按 \texttt{0.png, 1.png, \ldots} 自然排序，节点编号同时编码``沿路径前进的方向''，因此拓扑地图在使用上更接近一条按空间顺序排好的导航队列。

设拓扑节点图像沿路径排列为 $\mathcal{G}=(I_g^{(0)}, \ldots, I_g^{(M-1)})$，导航任务给定起点附近索引 $0$ 与目标索引 $g\le M-1$。系统维护一个状态化的``当前定位''指针 $c_t$，距离预测头只在以 $c_t$ 为中心、半径 $r$ 的局部窗口
\begin{equation}
\mathcal{W}_t = \{j : \max(c_t-r,\,0) \le j \le \min(c_t+r+1,\,g)\}
\end{equation}
式中，$\mathcal{W}_t$ 表示第 $t$ 个控制周期的候选节点窗口，$j$ 为候选节点索引，$c_t$ 为当前定位指针，$r$ 为窗口半径，$g$ 为目标节点索引；$\max(\cdot)$ 与 $\min(\cdot)$ 用于保证窗口不越过拓扑地图的起止边界。本文取$ r = 4 $，使得候选节点窗口兼顾执行效率与鲁棒性。在窗口内对当前观察 $\mathcal{O}_t$ 与每个候选节点 $I_g^{(j)}$ 计算距离预测 $\hat d_j$，并据此更新定位：
\begin{equation}
c_{t+1} = \mathrm{clip}\bigl(\arg\min_{j\in\mathcal{W}_t} \hat d_j,\; c_t-1,\; c_t+\Delta_{\max}\bigr),
\end{equation}
其中 $c_{t+1}$ 表示更新后的定位指针，$\hat d_j$ 表示当前观察到候选节点 $j$ 的预测距离，$\arg\min$ 选择预测距离最小的候选节点，$\mathrm{clip}(\cdot)$ 将结果限制在 $[c_t-1,c_t+\Delta_{\max}]$ 内；本文取 $\Delta_{\max}=3$，使定位指针每周期至多前进 3 个节点、至多回退 1 个节点，从而强制定位整体沿拓扑地图单向推进。

\subsection{航点表示的优势分析}

本文选择航点序列作为策略输出形式，而非直接预测底层速度命令（如线速度 $v$ 和角速度 $\omega$），这一设计决策基于以下三点考量。

第一，平台无关性。航点表示为局部坐标系下的二维位移序列，不与任何特定的运动学模型绑定。无论下游执行平台是差分驱动的轮式机器人还是具有复杂运动学的足式机器人（如 Lite3），同一条航点轨迹都可以通过不同的中层控制器进行跟踪。这种解耦使得高层策略的训练数据可以跨平台复用。

第二，多模态表达能力。在面对 T 形路口或走廊分叉等场景时，合理的导航行为可能包含``左转''和``右转''两个互不相容的模态。若使用单步速度命令的均值回归策略，两个模态的平均结果可能是``直行撞墙''。而航点序列结合扩散模型的生成能力，能够保留这种多模态分布，通过采样不同轨迹来表达不同的决策意图。

第三，闭环控制的友好性。中层控制器（如 PID 控制器或 MPC）可以直接将航点序列作为参考路径进行跟踪，这比将高层策略输出的速度命令直接下发到底层更加鲁棒，因为航点跟踪器可以根据实际执行情况进行局部修正。

航点序列还提供了比单步动作更丰富的决策信息。单步速度命令仅编码了当前时刻的瞬时意图，而航点序列编码了未来一段时间窗口内的完整运动意图。这种``前瞻性''信息对于中层控制器的预测性规划至关重要——控制器可以提前预判即将到来的转弯或减速需求，从而生成更平滑的底层控制信号。特别是对于足式机器人，步态切换和身体姿态调整需要提前规划，单步速度命令无法提供足够的前瞻信息。

围绕这一任务，本文在推理模块层面的工作可概括为三部分。第一，建立 NoMaD 的训练与推理基线，明确视觉编码器、距离预测头与扩散策略头之间的关系。第二，围绕部署可用性对推理层进行优化，重点研究 DDIM 推理、CFG 引导增强和 TTS 推理时搜索。第三，围绕视觉表征能力设计视觉编码器升级实验，并与基线配置进行对比。

\section{动作扩散策略与 NoMaD 模型机制}

\subsection{扩散模型与动作扩散策略}

\paragraph*{扩散模型基本原理}

扩散模型通过``逐步加噪、逐步去噪''的方式学习复杂分布\cite{ddpm2020}。在训练阶段，模型先把真实样本 $x_0$ 按照噪声调度扰动为 $x_t$，再学习在给定条件 $c$ 和时间步 $t$ 时预测加入的噪声。常用噪声预测损失可写为
\begin{equation}
\mathcal{L}_{\text{diff}} = \mathbb{E}_{x_0,\epsilon,t}\left[\left\|\epsilon - \epsilon_\theta(x_t, t, c)\right\|_2^2\right],
\end{equation}
其中 $\epsilon$ 为真实噪声，$\epsilon_\theta$ 为模型预测噪声，$c$ 表示条件信息。与图像生成不同，本文中的 $x_0$ 不是高维像素，而是局部航点轨迹
\begin{equation}
\mathbf{A} = [\mathbf{a}_1, \ldots, \mathbf{a}_H] \in \mathbb{R}^{H \times 2}.
\end{equation}
因此，扩散过程发生在低维轨迹空间中：前向过程向航点序列添加噪声，反向过程在视觉条件约束下逐步恢复出可执行的局部轨迹。本文采用的 NoMaD 配置中训练扩散步数为 $T=10$，远小于通用图像扩散模型常见的千步量级，这也是其能够进入实时导航部署讨论的前提。

将扩散模型用于导航时，其价值不在于生成视觉图像，而在于表达导航动作的多模态分布。具体而言，动作扩散策略在导航任务中具有以下优势：
\begin{enumerate}
    \item \textbf{多模态决策}：在走廊分叉、障碍绕行或目标视角不确定时，多个局部动作都可能合理，扩散策略可以通过采样保留不同候选，而不是把它们平均成一条不可执行轨迹；
    \item \textbf{时序一致性}：扩散对象是一段航点序列，而不是单个速度值，因此模型能够一次性生成具有前瞻性的局部轨迹，便于后续控制器跟踪；
    \item \textbf{条件生成}：历史观察、目标图像或拓扑节点图像可以作为去噪条件输入，使轨迹生成直接受到视觉目标约束；
    \item \textbf{部署可调}：采样步数、条件引导和候选筛选都可以在推理阶段调整，为边缘设备上的速度-质量权衡提供空间。
\end{enumerate}

\paragraph*{扩散采样与推理加速}

DDPM 使用完整反向扩散链生成样本，采样质量较稳定，但推理开销较高\cite{ddpm2020}。DDIM 在不重新训练模型的前提下，通过跳步采样减少反向去噪步数，从而显著降低推理时间\cite{ddim2020}。本文后续所说的``DDIM 推理加速''，即是在保持 NoMaD 已训练权重不变的条件下，把原始 $T=10$ 步采样压缩为 $S=5/3/2/1$ 等较少步数，并观察轨迹质量与推理时延之间的变化。

对于导航部署而言，DDIM 的意义不是单纯追求更快的模型推理，而是为闭环控制争取时间预算。真实机器人每个高层周期还包含相机读取、图像预处理、距离预测、航点到速度指令映射和通信下发等环节；因此扩散采样步数越少，系统越容易在边缘计算平台上形成稳定闭环。但步数过少也会造成轨迹退化，本文后续实验将专门比较 DDIM-1、DDIM-2、DDIM-3、DDIM-5 与 DDPM-10 的差异。

\paragraph*{Classifier-Free Guidance}

Classifier-Free Guidance（CFG）最初用于条件生成任务中的引导增强\cite{cfg2022}。其思想是在训练阶段同时学习有条件与无条件预测，在推理阶段通过两者线性组合增强条件约束。若条件分支噪声预测为 $\epsilon_{\text{cond}}$，无条件分支为 $\epsilon_{\text{uncond}}$，则引导后的噪声预测写为
\begin{equation}
\epsilon_{\text{cfg}} = (1+w)\epsilon_{\text{cond}} - w\epsilon_{\text{uncond}},
\end{equation}
其中 $\epsilon_{\text{cfg}}$ 表示引导后的噪声预测，$\epsilon_{\text{cond}}$ 表示条件分支噪声预测，$\epsilon_{\text{uncond}}$ 表示无条件分支噪声预测，$w$ 为引导强度。当 $w=0$ 时退化为普通条件推理；当 $w>0$ 时，模型会更强地朝向条件约束；当 $w$ 过大时，也可能带来分布偏移与不稳定。

在本文中，CFG 的作用是增强轨迹对目标图像的牵引能力。由于 NoMaD 训练时已经引入 goal mask，推理时可以把带目标图像的预测视为条件分支，把目标 token 替换为掩码 token 的预测视为无目标分支。需要注意的是，这里的``无目标''并非完全无信息：模型仍然接收历史观察，只是失去显式目标图像。因此 CFG 增强的是目标方向性，而不是重新定义整体行为先验。该机制与后文导航模式/探索模式的统一部署直接相关。

\paragraph*{扩散策略与 Test-Time Scaling}

扩散策略将扩散模型从图像生成推广到动作序列或轨迹序列生成\cite{diffuser2022,chi2025diffusion}。在具身智能与机器人控制领域，Diffuser 和 Diffusion Policy 表明扩散建模能够有效处理多步决策、长时序动作和多模态行为分布，因此被视为扩散模型在具身控制中的代表性应用。

具体而言，Diffuser\cite{diffuser2022} 将整个轨迹作为扩散对象，Diffusion Policy\cite{chi2025diffusion} 则只对动作序列进行扩散，并把视觉观察作为条件信息。NoMaD 的扩散策略头采用了类似后者的思路：视觉编码器先把历史观察和目标图像压缩为条件向量，扩散头再在该条件下生成未来局部航点序列。这样，扩散模型负责高层局部决策，中层控制器再把航点转为实际速度指令，形成与不同机器人平台解耦的接口。

在此基础上，近年来出现了测试时扩展（Test-Time Scaling, TTS）的思路\cite{ttsdiffusion2025,ttssearch2025}。其核心思想不是修改训练过程，而是在推理阶段使用额外计算预算生成多条候选轨迹，再通过打分函数进行选择。本文采用的是其中的 best-of-N 形式，即从多条候选航点轨迹中选择评分最高者用于执行。若生成 $N$ 条候选轨迹 $\{\mathbf{A}^{(i)}\}_{i=1}^N$，评分函数为 $s(\cdot)$，则最优轨迹可表示为
\begin{equation}
\mathbf{A}^{\ast} = \arg\max_{i\in\{1,\ldots,N\}} s\!\left(\mathbf{A}^{(i)} \mid \mathcal{O}_t, I_g\right).
\end{equation}
其中 $\mathbf{A}^{\ast}$ 表示被选中的最优候选轨迹，$\mathbf{A}^{(i)}$ 表示第 $i$ 条候选轨迹，$N$ 表示候选轨迹数量，$s(\cdot)$ 表示评分函数，$\mathcal{O}_t$ 表示当前历史观察，$I_g$ 表示目标图像。

在导航场景中，TTS 的评分函数不需要重新训练模型，而是可以利用轨迹几何属性和模型已有输出构造代理指标。例如，前向进展反映轨迹是否朝目标方向移动，平滑性反映相邻航点方向变化是否过大，目标一致性则反映候选轨迹是否更接近目标图像或拓扑节点。本文后续实验关注的不是无限增加候选数量，而是在边缘设备预算内判断 TTS-8、TTS-16 等配置是否能用较小代价改善候选选择。

需要强调的是，TTS 与 DDIM、CFG 作用位置不同。DDIM 决定``怎么采样''，CFG 决定``采样时如何增强条件''，而 TTS 决定``采样出多条候选后如何选择''。因此三者虽然都属于推理时优化，但不是简单相加关系，而是具有先后层次的组合关系。

\paragraph*{扩散模型、视觉 Transformer 与导航建模的关系}

扩散策略在视觉导航中并不是孤立使用的，它需要与视觉编码器共同工作。ViNT 使用 Transformer 融合历史观察与目标图像\cite{vint2023}，NoMaD 则在此基础上加入动作扩散策略\cite{nomad2023}，使视觉条件不再只服务于单一路径回归，而是作为去噪过程的条件输入。由此可见，本文后续讨论的视觉编码器升级、DDIM 采样加速、CFG 条件引导、TTS 候选筛选和四足平台部署，实际上对应同一条链路中的不同环节：先获得可靠视觉条件，再生成多模态航点候选，最后在实时闭环中选择并执行。

\subsection{NoMaD 基础模型结构}

NoMaD 由视觉编码器、距离预测头和扩散策略头三部分构成\cite{nomad2023}。视觉编码器负责把历史观察与目标图像编码为统一条件特征；距离预测头估计当前观察与目标之间的相对距离
（以离散时间步数为单位，表示从当前位置到达目标大约需要多少个导航步骤，而非物理距离）；扩散策略头则在该条件特征上生成未来局部航点轨迹。若记局部轨迹为
\begin{equation}
\mathbf{A} = [\mathbf{a}_1,\mathbf{a}_2,\ldots,\mathbf{a}_H], \qquad \mathbf{a}_i=(\Delta x_i,\Delta y_i),
\end{equation}
其中 $\mathbf{A}$ 表示完整的局部轨迹序列，$\mathbf{a}_i$ 表示第 $i$ 个航点，$H$ 表示预测步数，$\Delta x_i$ 和 $\Delta y_i$ 分别表示机器人局部坐标系下的前向与横向位移增量。
则 NoMaD 学习的是条件分布
\begin{equation}
p(\mathbf{A}\mid \mathcal{O}_t, I_g).
\end{equation}
式中，$p(\cdot)$ 表示条件轨迹分布，$\mathcal{O}_t$ 表示当前历史观察序列，$I_g$ 表示目标图像。

在 NoMaD 的视觉编码器部分，其底层基于 ViNT 的 Transformer 架构。具体而言，每帧观察图像首先通过卷积神经网络（Convolutional Neural Network, CNN）或视觉 Transformer（Vision Transformer, ViT）前端提取特征图，再经过全局池化与线性投影映射为统一的 token 表示。若历史上下文长度为 $K$，则模型将当前帧及其之前的 $K$ 帧图像编码为观察 token；目标图像与当前帧共同编码为目标 token。这些 token 被拼接为一个统一的序列，送入 Transformer 编码器进行联合注意力计算。形式化地，令观察 token 序列为 $\{\mathbf{z}_{\text{obs}}^{(k)}\}_{k=0}^{K}$，目标 token 为 $\mathbf{z}_{\text{goal}}$，则 Transformer 编码器的输入为
\begin{equation}
\mathbf{Z}_{\text{input}} = [\mathbf{z}_{\text{obs}}^{(0)}; \mathbf{z}_{\text{obs}}^{(1)}; \ldots; \mathbf{z}_{\text{obs}}^{(K)}; \mathbf{z}_{\text{goal}}],
\end{equation}
其中 $\mathbf{Z}_{\text{input}}$ 表示送入 Transformer 编码器的 token 序列，$\mathbf{z}_{\text{obs}}^{(k)}$ 表示第 $k$ 帧历史观察对应的观察 token，$\mathbf{z}_{\text{goal}}$ 表示目标 token，$K$ 为历史上下文长度参数；该序列共 $K+2$ 个 token。经过多层自注意力后，输出的 token 表征即为共享条件空间中的统一条件特征。

在 ViNT\cite{vint2023} 的原始设计中，Transformer\cite{transformer2017} 编码器采用多层标准自注意力结构。每帧图像经过 EfficientNet-B0\cite{efficientnet2019} 前端后形成图像特征，再由线性投影映射为 Transformer 可处理的 token。为了区分不同时间步的观察，模型为各帧 token 添加帧级位置编码。Transformer 的输出 token 经过池化后产生固定维度的条件向量，该向量同时被距离预测头和扩散策略头使用，因此视觉编码器的表征质量会同时影响目标距离估计与局部轨迹生成。

\paragraph*{输入输出形式}

根据本文基线设置，NoMaD 的输入由历史视觉观察与目标图像构成。实验中采用当前帧及其前三帧作为历史观察序列，并在导航模式下额外输入目标图像。输出则为固定长度的局部轨迹序列，每个航点用局部坐标系下的二维位移表示：
\begin{equation}
\mathbf{a}_i = (\Delta x_i, \Delta y_i), \qquad i=1,\ldots,H.
\end{equation}
式中，$\mathbf{a}_i$ 表示第 $i$ 个局部航点，$\Delta x_i$ 与 $\Delta y_i$ 分别表示局部坐标系下前向和横向位移，$H$ 表示预测轨迹长度。
整段轨迹写为
\begin{equation}
\mathbf{A} = [\mathbf{a}_1,\mathbf{a}_2,\ldots,\mathbf{a}_H].
\end{equation}
式中，$\mathbf{A}$ 表示由 $H$ 个航点组成的完整局部轨迹。

这一表示的优点在于，它比直接输出底层速度命令更适合作为平台无关的高层接口，也比全局路径更适合闭环局部控制。对于足式平台，高层输出局部轨迹、中层完成控制映射的方式尤为关键。

\paragraph*{视觉编码器架构}

NoMaD 默认采用 EfficientNet-B0 作为视觉编码器骨干\cite{efficientnet2019}。EfficientNet-B0 是 EfficientNet 系列的基础模型，通过复合缩放（compound scaling）策略在深度、宽度和分辨率三个维度上进行统一缩放，在 ImageNet 上以约 5.3\,M 参数量达到了优异的精度-效率平衡。其核心构建块为移动倒置瓶颈卷积（Mobile Inverted Bottleneck Convolution, MBConv），采用深度可分离卷积和 Squeeze-and-Excitation 注意力模块。

在 NoMaD 的视觉编码流程中，内部实例化了两个 EfficientNet-B0：一个只处理单帧观察（3 通道输入），另一个处理``最后一帧观察 + 目标图像''的 6 通道拼接输入。二者权重独立、架构几乎相同，只在输入卷积的通道数上有差别。这一设计使得目标分支在特征层就完成了当前帧与目标帧的早期融合，但也使得视觉编码器部分的参数量近似等于两个 EfficientNet-B0 之和，再加上一个输出投影层（将 1280 维骨干网络特征压缩到 256 维 token 维度）。

两个 EfficientNet-B0 接收 $96 \times 96$ 的 RGB 图像作为输入，提取特征后分别输出一个固定维度的视觉表示。该特征向量随后被投影为标准化的 token 表示，用于后续的条件拼接。具体而言，每帧观察图像经过第一个编码器后得到特征 $\mathbf{z}_i \in \mathbb{R}^d$，其中 $d$ 为 token 维度（本文配置下 $d=256$）；目标 token $\mathbf{z}_g$ 由第二个编码器以相同方式得到。

选择 EfficientNet-B0 而非更大的 EfficientNet 变体（如 B3 或 B5）是出于推理效率的考虑。在边缘设备上，视觉编码器的计算开销直接影响整体推理频率，而 B0 的 5.3\,M 参数量在精度与效率之间提供了合理的折中；由于 NoMaD 中需要同时维护两个 EfficientNet-B0 实例，骨干规模的选择对整体部署时延具有放大效应，这进一步佐证了 B0 作为默认选型的合理性。

\paragraph*{Token 构建与条件拼接}

NoMaD 的视觉条件编码器由观察编码器和目标编码器两部分组成。观察编码器独立处理历史观察帧，目标编码器则把当前帧与目标图像共同作为输入，使目标 token 同时携带``当前在哪''和``要去哪''两类信息。这种早期融合方式有助于减轻后续自注意力层的建模负担。

历史观察 token 与目标 token 经位置编码后送入 Transformer 自注意力编码器，再对所得序列做自注意力（Self-Attention, SA）编码与平均池化（Average Pooling, AvgPool），得到固定维度的视觉条件向量：
\begin{equation}
\mathbf{c} = \text{AvgPool}\bigl(\text{SA}\bigl([\mathbf{z}_{t-K},\ldots,\mathbf{z}_t,\mathbf{z}_g]\bigr)\bigr).
\end{equation}
其中 $\mathbf{c}$ 表示池化后的视觉条件向量，$\mathbf{z}_{t-K}$ 到 $\mathbf{z}_t$ 表示历史观察 token，$\mathbf{z}_g$ 表示目标 token，$\text{SA}(\cdot)$ 表示自注意力编码器，$\text{AvgPool}(\cdot)$ 表示平均池化操作。这一条件向量同时作为距离预测头和扩散策略头的输入。

\paragraph*{距离预测头与模型训练目标}

距离预测头与扩散策略头共享同一条视觉条件空间，这意味着视觉编码器的改动会产生连锁效应。假设原始编码器输出的条件特征维度为 $d_{\text{orig}}$，新编码器输出维度为 $d_{\text{new}}$，则即使通过线性投影层将 $d_{\text{new}}$ 映射到 $d_{\text{orig}}$，投影后的特征分布也与原始特征不同。距离预测头是一个在原始特征分布上训练的回归网络，输入分布的偏移会直接导致距离预测不准确。因此，本文在编码器升级实验中采用端到端微调策略，同时更新编码器适配层、距离预测头和扩散策略头的参数。这种端到端微调策略虽然计算成本较高，但确保了三个组件在新的特征空间中重新对齐，避免了因局部更新导致的性能退化。

NoMaD 由视觉编码器、距离预测头和扩散策略头三部分组成\cite{nomad2023}。视觉编码器负责将历史观察与目标条件编码为统一特征；距离预测头输出当前观察到目标的相对距离估计；扩散策略头在该条件上生成局部轨迹样本。

训练时，总损失由距离回归损失与扩散噪声预测损失组成，可写为
\begin{equation}
\mathcal{L} = \alpha \mathcal{L}_{dist} + (1-\alpha)\mathcal{L}_{diff}.
\end{equation}
其中 $\mathcal{L}$ 表示总训练损失，$\mathcal{L}_{dist}$ 约束候选目标排序能力，$\mathcal{L}_{diff}$ 约束局部轨迹生成质量，$\alpha$ 表示距离损失与扩散损失之间的权重系数。

关于损失权重 $\alpha$ 的选择策略，需要注意以下两点。首先，$\mathcal{L}_{dist}$ 通常采用 $L_1$ 或 $L_2$ 回归损失，其数值尺度与扩散噪声预测损失 $\mathcal{L}_{diff}$ 存在差异，因此 $\alpha$ 实际上同时承担了任务权重和尺度归一化的双重角色。其次，距离预测头的梯度会回传至视觉编码器，这意味着 $\alpha$ 的选择会影响编码器学到的特征偏向——较大的 $\alpha$ 倾向于让编码器学习距离敏感的特征，较小的 $\alpha$ 则让编码器更侧重于轨迹生成所需的空间结构特征。

距离预测头与视觉编码器是直接耦合的，因此更换视觉编码器后，距离预测分支必须同步重新训练，否则距离头与轨迹头将共享不一致的条件分布。

\paragraph*{推理链路的统一封装}

在推理阶段，系统先编码观察与目标，再在需要时进行候选节点距离评估，最后通过扩散采样生成轨迹。

统一推理模块的设计遵循参数化管理原则：模型权重、采样方式和候选筛选设置在统一入口处确定，使 DDIM、CFG 和 TTS 实验能够共享同一套推理流程。同时，统一推理模块也提供标准化输出，包括候选轨迹集合、距离预测值和推理时间统计，方便下游评估与闭环系统直接使用。

\subsection{视觉掩码与导航/探索统一建模}

NoMaD 的一个关键机制是目标掩码（goal mask）。训练时，模型以一定概率遮蔽目标 token，使其同时经历``有目标条件''和``无显式目标条件''两种情况\cite{nomad2023}。这并不意味着模型在无目标条件时进行随机游走，而是意味着它会学习在当前视觉上下文中生成连续、可执行且符合数据轨迹分布的探索性行为。正因为如此，NoMaD 才能在部署时同时支持导航模式与探索模式。当 goal mask 取 0 时，目标 token $\mathbf{z}_g$ 正常参与 self-attention，模型处于``带目标导航''模式；当 goal mask 取 1 时，$\mathbf{z}_g$ 所在位置被置为 padding 并在池化时去掉权重，模型退化为``无目标探索''模式。这一机制使得同一套权重既可用于导航也可用于探索，也是后续 CFG 引导能同时使用``带目标''与``不带目标''两次前向的直接原因。

goal mask 的设计还有一个重要的技术意义：它使得模型在训练时自然地学习了
``当前观察本身蕴含的行为先验''。即使没有目标指引，训练数据中的轨迹通常
也遵循特定的行为模式（如沿道路行驶、避开障碍物），goal mask 使模型能够
将这些模式内化为无条件生成能力。

在数学表述上，goal mask 的训练过程可以描述如下。设 goal mask 概率为 $p_{\text{mask}}$，对于每个训练样本，以概率 $p_{\text{mask}}$ 将目标 token $\mathbf{z}_{\text{goal}}$ 替换为可学习的掩码 token $\mathbf{z}_{\text{mask}}$。因此模型在训练过程中优化的是混合目标：
\begin{equation}
\mathcal{L} = p_{\text{mask}} \cdot \mathcal{L}_{\text{diff}}(\epsilon_\theta(x_t, t, \mathbf{z}_{\text{obs}}, \mathbf{z}_{\text{mask}})) + (1 - p_{\text{mask}}) \cdot \mathcal{L}_{\text{diff}}(\epsilon_\theta(x_t, t, \mathbf{z}_{\text{obs}}, \mathbf{z}_{\text{goal}})).
\end{equation}
式中，$\mathcal{L}$ 表示混合训练损失，$p_{\text{mask}}$ 表示目标掩码概率，$\mathbf{z}_{\text{obs}}$ 表示观察 token，$\mathbf{z}_{\text{mask}}$ 表示掩码 token，$\mathbf{z}_{\text{goal}}$ 表示目标 token，$\epsilon_\theta(\cdot)$ 表示噪声预测网络。在本文的配置中，$p_{\text{mask}}$ 设置为 $0.5$ ，确保两种模式都获得充分训练。值得注意的是，goal mask 机制与 CFG 中的条件随机丢弃（condition dropout）在形式上高度一致——两者都是在训练时以一定概率移除条件信息。因此 goal mask 实际上内在地为 CFG 推理提供了基础：在推理时，将条件分支（提供目标 token）与无条件分支（使用掩码 token）的噪声预测进行 CFG 组合，即可实现对目标方向的引导增强。这种设计使得探索能力与导航增强能力共享同一训练框架。

在部署阶段，探索模式与导航模式的切换仅需改变推理时的条件输入：提供真实目标 token 时进入导航模式，提供掩码 token 时进入探索模式。两种模式之间的切换不需要加载不同的模型权重或改变网络结构，这大大简化了部署系统的设计。

\section{数据集、实验设备与基线推理验证}

\subsection{GoStanford 数据集与数据预处理}

本文所有离线实验均基于 GoStanford 数据集进行。该数据集来源于斯坦福大学校园环境中通过自主采集机器人记录的视觉导航轨迹，是 NoMaD 相关研究采用的标准训练与评估数据来源之一\cite{gnm2022,vint2023,nomad2023}。数据集中的每条轨迹包含按时间顺序排列的第一人称 RGB 图像帧和对应的位姿信息。

GoStanford 原始数据集的场景多样性是其作为标准评估数据集的重要优势，数据采集覆盖了斯坦福大学校园中的室内走廊、室外道路、建筑入口、停车区域等多种环境类型。每条轨迹的长度从几十帧到数百帧不等，对应数十米到数百米的实际行驶距离。图像帧的采集频率约为 4\,Hz，位姿信息由里程计或 GPS 提供，精度足以用于轨迹级别的训练监督。

本文使用的本地训练与离线评估子集来自 GoStanford 中的室内路线，未包含室外道路、强日照或开阔场地等数据。在离线实验中，每次推理从轨迹中提取连续观察帧与目标帧，构建标准化测试样例。DDIM、CFG 与编码器实验使用 24 组测试样例；TTS 补充实验为控制组合规模使用 12 组测试样例，但保持相同的样例构造规则和统计口径。

从原始轨迹到模型输入之间存在一个标准化的数据预处理流程。首先，RGB 图像从原始分辨率（通常为 $640 \times 480$）对齐至模型要求的输入尺寸（$96 \times 96$），缩放过程使用双线性插值。其次，像素值从 $[0, 255]$ 归一化至 $[0, 1]$ 范围。最后，根据历史上下文长度从轨迹中提取连续帧作为历史观察，并从同一轨迹的未来位置选取目标帧。

测试样例的构建遵循以下原则：当前观察与目标帧之间的时间间隔覆盖短距离（5--10 帧）和中距离（20--50 帧）两种范围，以确保评估涵盖不同难度级别。每个样例包含完整的历史观察序列、目标图像和对应的真实轨迹标签，使得所有实验在完全相同的数据条件下进行比较。

值得说明的是，24 组测试样例的数量虽然有限，但其设计覆盖了直行、转弯、宽阔区域和狭窄走廊等多种典型场景类型。在离线统计实验中，这一规模足以反映不同配置之间的趋势性差异，同时保持单次完整实验的运行时间在可接受范围内。对于需要更高统计置信度的结论，本文通过报告 95\% 置信区间（95\% Confidence Interval, CI95）来量化均值估计的不确定性。

\subsection{感知输入与实验设备}

本文系统采用纯 RGB 单目视觉作为唯一感知输入，不依赖深度传感器、激光雷达或惯性测量单元。这一设计选择与 NoMaD 原始框架一致，即高层导航策略仅以图像观察和目标图像为输入，不需要额外传感模态。

纯视觉感知的优势在于硬件成本低、安装简单、且与人类的导航感知方式最为接近。其主要局限在于：（1）缺乏显式的深度信息，无法直接判断障碍物距离；（2）对光照变化和动态遮挡敏感；（3）单目视觉的尺度模糊性使得绝对距离估计困难。NoMaD 通过学习大量导航轨迹数据来隐式弥补这些局限。

在离线实验阶段，训练与统计实验运行在配备 NVIDIA RTX 4090 的计算机上；在 MuJoCo 仿真阶段，相机图像由 MuJoCo 渲染器以第一人称视角生成；在真机部署阶段，使用 USB 单目相机接入 Jetson Orin，输出分辨率为 $640\times480$。

RTX 4090 与 Jetson Orin 之间的算力差距是本文实验设计中需要特别关注的因素。RTX 4090 适合承担离线训练和统计实验，而 Jetson Orin 属于机载边缘计算平台，受功耗、散热和统一内存资源约束更强。这意味着在 RTX 4090 上可接受的推理时延，在 Jetson Orin 上仍需要通过板端基准测试重新确认。因此，本文在离线实验中特别关注时延指标的绝对值而非仅关注相对加速比，以便为部署阶段的配置选择提供直接参考。

\subsection{基线推理与评价指标}

为给后续所有优化实验建立统一参考，本文首先复现了原始 NoMaD 离线推理流程。输出结果表明，原始模型参数量约为 19,049,675。需要区分两种不同口径的时延：在端到端单次运行中，包含图像加载、编码、DDPM-10 采样与结果后处理的整体耗时约为 0.1250\,s；而在本章后续使用的 24 组测试样例统计实验中（见表~\ref{tab:ddim-results}），\texttt{ddpm\_10} 的纯扩散采样平均时延约为 40\,ms，CI95 为 $\pm$1.37\,ms。两者数量级差异的根本原因是前者计入了一次性模型构建、设备预热与图像预处理开销，而后者在预热阶段之后测量循环体内部的推理时间。由于后续 DDIM、CFG、TTS 与视觉编码器对比实验都运行在统一的统计流程与评价设置下，本文把``40\,ms 量级''视为基线推理时延的有效参考，而把``0.125\,s''仅作为单次端到端流程的补充记录。

关于参数量的构成，19.05\,M 参数中视觉条件编码器约占 15.18\,M（含两个 EfficientNet-B0、投影层、位置编码与 4 层 self-attention），扩散策略头（条件一维 U-Net，ConditionalUnet1D）约占 3.85\,M，距离预测头约占 0.02\,M。由此可见视觉编码器是主要参数来源，更换视觉编码器对总参数量的影响取决于新骨干网络的规模：若替换为 DINOv2-Small（22\,M 骨干网络）或 ConvNeXt-Tiny（27\,M 骨干网络）将使总参数量明显上升；若保持骨干网络在 B0 量级则总参数量相近。

扩散策略头中的 U-Net 架构采用了多尺度特征融合和条件注入机制。条件向量 $\mathbf{c}$ 通过 FiLM（Feature-wise Linear Modulation）机制注入到 U-Net 的各个分辨率层级中，使得噪声预测网络能够在每一步去噪中都感知到当前的视觉条件和目标信息。这种设计虽然增加了参数量，但保证了扩散过程对条件信号的充分响应。

关于推理频率的部署含义，40\,ms 的纯采样时延在 RTX 4090 上对应约 25\,Hz 的理论上限，但叠加图像预处理、消息传递或可视化后，端到端频率通常会明显低于该理论值。在边缘设备（如 Jetson Orin）上，实际频率还会受到功耗模式、散热状态、相机驱动和 PyTorch/CUDA 版本影响，因此不能仅按桌面 GPU 与边缘 GPU 的标称算力比例线性外推。本文把 DDIM 加速作为部署优化的直接动机，但具体真机可用频率仍以后续 Orin 阶段实测为准。

此外，$8 \times 8$ 的轨迹采样规格表示每次推理生成 8 条候选轨迹，每条轨迹包含 8 个航点。8 个航点的长度在默认配置下对应约 2--3 秒的未来规划窗口，这一时间尺度既足以覆盖局部导航决策（如是否转弯），又不至于因规划太远而积累过大误差。

\paragraph*{指标的形式化定义}

为确保实验可复现性，本文给出各指标的形式化定义。

\textbf{Latency} 定义为单次推理的端到端耗时，包含编码、去噪和后处理，单位为毫秒：
\begin{equation}
\text{Latency} = t_{\text{end}} - t_{\text{start}}.
\end{equation}
式中，$t_{\text{start}}$ 与 $t_{\text{end}}$ 分别表示单次推理开始和结束的时间戳，二者差值即端到端推理耗时。

\textbf{CI95} 表示均值的 95\% 置信区间半径，基于 $t$ 分布计算：
\begin{equation}
\text{CI95} = t_{0.975, n-1} \cdot \frac{s}{\sqrt{n}},
\end{equation}
其中 $t_{0.975,n-1}$ 表示自由度为 $n-1$ 的 $t$ 分布在 0.975 分位处的临界值，$s$ 为样本标准差，$n$ 为测试样例数量。

\textbf{MSE vs DDPM-10} 衡量某配置生成轨迹均值与基线 DDPM-10 生成轨迹均值之间的均方误差：
\begin{equation}
\text{MSE} = \frac{1}{H} \sum_{i=1}^{H} \|\bar{\mathbf{a}}_i^{\text{test}} - \bar{\mathbf{a}}_i^{\text{base}}\|^2,
\end{equation}
其中 $\text{MSE}$ 表示均方误差，$H$ 表示预测轨迹长度，$\bar{\mathbf{a}}_i^{\text{test}}$ 表示测试配置下第 $i$ 个航点的候选均值，$\bar{\mathbf{a}}_i^{\text{base}}$ 表示基线配置下第 $i$ 个航点的候选均值，$\|\cdot\|^2$ 表示欧氏距离平方。

\textbf{Forward Progress} 定义为轨迹在主前进方向（$x$ 轴）上的累计位移：
\begin{equation}
\text{FP} = \sum_{i=1}^{H} \Delta x_i.
\end{equation}
式中，$\text{FP}$ 表示前向进展指标，$\Delta x_i$ 表示第 $i$ 个航点的前向位移增量，$H$ 表示轨迹长度。

\textbf{Lateral Abs} 定义为轨迹在横向（$y$ 轴）上的累计绝对位移：
\begin{equation}
\text{LA} = \sum_{i=1}^{H} |\Delta y_i|.
\end{equation}
式中，$\text{LA}$ 表示横向绝对偏摆指标，$\Delta y_i$ 表示第 $i$ 个航点的横向位移增量，$|\cdot|$ 表示绝对值。

\textbf{Smoothness} 衡量相邻航点之间方向变化的一致性，定义为相邻位移向量差的范数均值：
\begin{equation}
\text{Smooth} = \frac{1}{H-1} \sum_{i=1}^{H-1} \|\mathbf{a}_{i+1} - \mathbf{a}_i\|.
\end{equation}
式中，$\text{Smooth}$ 表示平滑性代价，$\mathbf{a}_{i+1}-\mathbf{a}_i$ 表示相邻航点之间的位移变化，$\|\cdot\|$ 表示欧氏范数。

\paragraph*{统计显著性与多指标分析原则}

本文采用多指标联合分析而非单一指标排序，原因在于导航任务的优化目标本质上是多目标的。仅优化前进性可能导致激进轨迹，仅优化平滑性可能导致过于保守的运动。通过同时报告前向进展、横向偏差、平滑性和时延，可以判断某个配置是否在所有维度上都可接受，而不是在某一维度上表现突出但在其他维度上严重退化。

在统计检验层面，由于本文的离线实验样本量为 24 组测试样例，属于小样本范畴。对于小样本比较，本文主要依赖 CI95 的重叠程度来判断差异的显著性：若两个配置的 CI95 不重叠，则认为差异具有统计意义；若 CI95 部分重叠，则需结合效应量大小（即均值差与标准差之比）进行综合判断。这种方法比直接进行 $p$ 值检验更适合本文的实验规模和多次比较场景。

其中，CI95 并不是新的性能指标，而是均值稳定性的统计描述。若某个配置平均值较优但 CI95 很宽，说明其结果在不同测试样例间波动较大。前向进展也不能单独解释为越大越好，因为过大的前进量可能是激进采样带来的分布偏移，必须结合均方误差、横向偏差和轨迹平滑性一起分析。

\section{DDIM 推理加速与 CFG 引导增强实验}

\subsection{DDIM 推理加速实验}

\paragraph*{理论动机}

DDIM 的核心思想是将扩散模型的随机微分方程（Stochastic Differential Equation, SDE）采样过程转换为确定性常微分方程（Ordinary Differential Equation, ODE）求解过程\cite{ddim2020}。在标准 DDPM 中，反向去噪过程由以下随机递推描述：
\begin{equation}
\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left(\mathbf{x}_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)\right) + \sigma_t \mathbf{z},
\end{equation}
其中 $\mathbf{x}_t$ 与 $\mathbf{x}_{t-1}$ 分别表示当前和上一去噪时间步的轨迹噪声样本，$\alpha_t$ 与 $\bar{\alpha}_t$ 表示单步和累计噪声调度系数，$\boldsymbol{\epsilon}_\theta(\mathbf{x}_t,t)$ 表示模型预测噪声，$\sigma_t$ 表示随机噪声强度，$\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 表示标准高斯噪声。DDIM 的关键洞察是：当令随机项 $\sigma_t = 0$ 时，上述过程退化为确定性的 ODE 积分：
\begin{equation}
\mathbf{x}_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \cdot \hat{\mathbf{x}}_0(\mathbf{x}_t, t) + \sqrt{1-\bar{\alpha}_{t-1}} \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t),
\end{equation}
其中 $\hat{\mathbf{x}}_0(\mathbf{x}_t,t)$ 是基于当前噪声预测得到的干净样本估计，$\bar{\alpha}_{t-1}$ 表示上一时间步的累计保留系数，其他符号含义与上式一致。

由于 ODE 的解路径是确定性的且连续的，可以在时间轴上使用更大的步长进行积分而不引入额外随机噪声的累积。这就是 DDIM 能够用更少步数完成去噪的数学基础——本质上是用粗粒度的数值积分近似原始的细粒度 ODE 轨迹。步数越少，积分越粗糙，但对于 smooth 的 ODE 解路径，适度的步数减少不会显著改变最终结果。

从数值分析的角度，DDIM 的步数减少可以类比为 ODE 求解器中步长的增大。对于一阶 Euler 方法，截断误差与步长 $h$ 成正比；而 DDIM 的更新规则实际上对应一种隐式的高阶积分格式，因此在步数适度减少时能保持较小的截断误差。但当步数降至极端（如仅 1 步）时，单步积分的假设不再成立，误差会急剧增大。

\paragraph*{实验设计}

DDIM 的作用是在不重新训练模型的情况下减少扩散去噪步数，从而降低推理时延\cite{ddim2020}。本文以\texttt{ddim\_x}来定义采用 DDIM 采样 $x$ 步的配置。本文在统一实验流程中比较 \texttt{ddpm\_10}、\texttt{ddim\_10}、\texttt{ddim\_5}、\texttt{ddim\_3}、\texttt{ddim\_2} 和 \texttt{ddim\_1} 六种配置，测试集共包含 24 组测试样例。该实验围绕以下两个核心问题展开：一是减少去噪步数后能够获得多大推理加速，二是加速后的轨迹分布是否仍保持在可接受范围内。

六种配置的选择覆盖了相比于基线，从``不减少步数''到``极端压缩至单步''的完整频谱。\texttt{ddim\_10} 与 \texttt{ddpm\_10} 步数相同，用于验证 DDIM 在不减步时是否引入额外偏差；\texttt{ddim\_5} 和 \texttt{ddim\_3} 代表中等程度的加速；\texttt{ddim\_2} 代表较为激进但仍可控的加速；\texttt{ddim\_1} 则代表理论极限，用于探测 DDIM 的失效边界。这种全频谱设计使得本文能够精确定位速度与质量的平衡点。

\texttt{ddim\_10} 与 \texttt{ddpm\_10} 的 MSE 仅为 0.0062，说明在相同步数下 DDIM 的确定性采样与 DDPM 的随机采样生成的轨迹均值几乎一致，验证了 DDIM 的理论无损性。\texttt{ddim\_5} 在步数减半的情况下 MSE 反而略低于 \texttt{ddim\_10}（0.0048 vs 0.0062），这可能源于采样噪声的统计波动，也说明 5 步 ODE 积分的截断误差仍然可以忽略。\texttt{ddim\_3} 的 MSE 上升至 0.0124，开始出现可观测的分布偏移但仍在可控范围内。\texttt{ddim\_2} 的 MSE 为 0.0210，虽然进一步升高但 Forward Progress 仅从 6.50 变为 6.65，偏移幅度有限。

针对第一个问题，结果表明 DDIM 的确能显著降低推理时延，其中 \texttt{ddim\_2} 已接近 5 倍加速。针对第二个问题，\texttt{ddim\_2} 在 MSE 与 Forward Progress 上仍保持相对平衡，说明它不是以严重破坏轨迹分布为代价换取速度。相比之下，\texttt{ddim\_1} 虽然最快，但 MSE 大幅升高，说明轨迹已明显偏离基线分布，不适合作为稳定部署方案。

从速度-质量 Pareto 前沿的角度分析，\texttt{ddim\_2} 到 \texttt{ddim\_5} 构成了一段有效的 Pareto 前沿：在这个范围内，每减少一步都能带来显著的时延收益，而 MSE 增长仍在可控范围内。\texttt{ddim\_1} 则明显偏离了这一前沿，属于``过度压缩''区域。

因此，本文将 \texttt{ddim\_2} 视为后续闭环验证中更值得优先考虑的推理配置。该结果表明，扩散策略并不必然意味着``质量高但太慢''，通过合理采样调度，NoMaD 可以进入更接近真实部署的时延区间。

\subsection{CFG 引导增强实验}

\paragraph*{理论分析}

Classifier-Free Guidance（CFG）的核心思想是在推理时通过线性外推来增强条件信号对生成结果的影响\cite{cfg2022}。具体来说，CFG 修改了扩散模型的噪声预测（score function）为：
\begin{equation}
\tilde{\boldsymbol{\epsilon}}_\theta(\mathbf{x}_t, t, \mathbf{c}) = (1+w) \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \mathbf{c}) - w \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \varnothing),
\end{equation}
其中 $\tilde{\boldsymbol{\epsilon}}_\theta$ 表示 CFG 修正后的噪声预测，$\mathbf{x}_t$ 表示当前噪声样本，$t$ 表示去噪时间步，$\mathbf{c}$ 为条件向量（包含观察和目标信息），$\varnothing$ 表示空条件（训练时通过随机 dropout 条件实现），$w$ 为引导权重。

当 $w=0$ 时，退化为标准的条件采样；当 $w>0$ 时，生成结果在条件方向上被``放大''，使轨迹更强烈地朝向目标方向偏移；当 $w<0$ 时，则产生反向引导效果。从概率密度的角度，CFG 实质上是在对数概率空间中将条件分布与无条件分布的差异进行缩放：
\begin{equation}
\log \tilde{p}(\mathbf{x} \mid \mathbf{c}) \propto (1+w) \log p(\mathbf{x} \mid \mathbf{c}) - w \log p(\mathbf{x}).
\end{equation}
式中，$\tilde{p}(\mathbf{x}\mid\mathbf{c})$ 表示经 CFG 修正后的条件分布，$p(\mathbf{x}\mid\mathbf{c})$ 表示原始条件分布，$p(\mathbf{x})$ 表示无条件先验分布，$\propto$ 表示两侧相差归一化常数。这意味着 $w$ 越大，生成分布越集中于条件分布的高概率区域，同时远离无条件先验的模态。

\paragraph*{实验设计}

CFG 的目标是在推理阶段增强轨迹对目标条件的响应\cite{cfg2022}。本文选取 $w\in\{-1.0,0.0,0.5,1.0,2.0,4.0\}$ 六组配置进行比较，旨在回答引导强度能否提升目标牵引，以及这种提升是否会带来不可接受的分布偏移和时延开销。

负值引导（$w=-1.0$）被包含在实验中，目的是验证反向引导是否会导致轨迹偏离目标方向。如果 $w=-1.0$ 的 Forward Progress 显著低于 $w=0.0$，则说明 CFG 的条件引导方向确实与目标方向一致，从而间接验证了 CFG 机制在导航任务中的有效性。

\paragraph*{实验结果与分析}

围绕上述问题，结果表明适度的 CFG 能提高轨迹对目标方向的响应，但代价是更高的推理时延和潜在的分布偏移。从表~\ref{tab:cfg-results} 可以看到，$w=0.0$ 时推理时延约为 42.65\,ms，而 $w \geq 0.5$ 后时延跃升至约 78--80\,ms，这是因为 CFG 需要同时执行条件分支与无条件分支的噪声预测。CFG 的每一步去噪都需要对噪声预测网络进行两次前向传播——一次使用完整条件 $\mathbf{c}$，一次使用空条件 $\varnothing$——然后将两次预测结果进行线性组合。因此，CFG 的计算成本近似为非 CFG 推理的 2 倍。实验中 $w=0.0$ 到 $w=0.5$ 的时延跳变（42.65\,ms $\to$ 78.27\,ms）正好反映了这一理论预期。

在轨迹质量方面，$w=1.0$ 的 Forward Progress 最高（8.573），Lateral Abs 仍保持适度（2.901），说明该配置在前进性和稳定性之间表现较为均衡。而 $w=4.0$ 时 Shift 高达 0.5133，Lateral Abs 上升至 3.089，表明过强的引导会导致分布偏移与横向偏摆。

关于最优引导尺度的选择，本文认为应遵循以下准则：（1）引导强度不应使 Shift 指标超过 0.2，以避免显著的分布偏移；（2）在满足（1）的前提下，优先选择 Forward Progress 较高的配置；（3）必须考虑时延代价——如果 CFG 带来的质量提升不能补偿 2 倍时延的代价，则不建议开启。

从实验数据来看，$w=-1.0$ 的反向引导在 Shift 和 Forward Progress 上与 $w=0.0$ 差异极小，说明轻微的反向引导对轨迹分布的影响可以忽略。$w=0.5$ 和 $w=1.0$ 的 Shift 分别为 0.0160 和 0.0476，均在 0.2 的阈值以内，属于可接受范围。$w=2.0$ 的 Shift 为 0.1438，虽未超过阈值但已接近边界，提示进一步增大引导可能带来不稳定性。由此可见，CFG 可以增强目标响应，但其收益必须与约 2 倍时延开销和分布偏移风险共同权衡。综合以上分析，本文将 CFG 定位为可调部署旋钮，而非必须开启的固定默认项。

\section{TTS 推理时搜索与视觉编码器升级实验}

\subsection{TTS 推理时搜索实验}

\paragraph*{实验设计}

TTS 的作用是把额外预算用于``候选生成与选择''，而非用于修改训练过程\cite{ttsdiffusion2025,ttssearch2025}。在本文中，TTS 被设计为推理层的外层搜索组件：先用当前采样配置生成多条候选轨迹，再根据目标一致性、前进性和平滑性综合打分，最终选择一条更适合执行的轨迹。实验重点比较不同预算下的轨迹质量收益，以及它与 DDIM、CFG 的组合关系。

\paragraph*{评分函数设计}

TTS 的核心在于评分函数的设计。本文采用加权多目标评分函数：
\begin{equation}
\text{Score}(\mathbf{A}) = \beta_1 \cdot \text{FP}(\mathbf{A}) - \beta_2 \cdot \text{LA}(\mathbf{A}) - \beta_3 \cdot \text{Smooth}(\mathbf{A}),
\end{equation}
其中 $\text{Score}(\mathbf{A})$ 表示候选轨迹 $\mathbf{A}$ 的综合评分，$\text{FP}(\mathbf{A})$ 为前进性，$\text{LA}(\mathbf{A})$ 为横向绝对偏摆，$\text{Smooth}(\mathbf{A})$ 为平滑性代价，$\beta_1, \beta_2, \beta_3$ 为权重系数。

评分函数中权重系数的选择需要根据具体部署场景进行调整。在开阔环境中，可以增大 $\beta_1$ 以鼓励更积极的前进；在狭窄走廊中，应增大 $\beta_2$ 以抑制横向偏摆；在需要精细控制的场景中，$\beta_3$ 应占主导以保证轨迹平滑性。本文在离线实验中采用固定权重配置，但在部署阶段可以根据场景类型动态调整。

\paragraph*{计算预算分配策略}

TTS 的计算开销与候选轨迹数（budget）总体正相关。设单次采样耗时为 $\tau$，则 TTS-$K$ 的总耗时可近似表示为候选生成开销与评分开销之和，其中评分与排序通常只占很小比例。由于实际实现会复用批量张量计算，耗时不会严格等于 $K \cdot \tau$。因此，DDIM 加速节省的时间预算可以部分重新分配给 TTS，形成``用更快的单次采样换取更多候选''的策略。

这种预算分配思路可以形式化为一个受约束的优化问题：在总时延预算 $T_{\max}$ 的约束下，选择 DDIM 步数 $S$ 和 TTS budget $K$ 以最大化轨迹质量。由于 $K \cdot \tau(S) \leq T_{\max}$，减少 $S$（加速单次采样）就能增大 $K$（增加候选数量），两者之间存在自然的折中关系。

\paragraph*{实验组织方式}

为了保证结论具有统计意义，本文将 TTS 实验组织为三层：单因素实验，用于比较是否开启 TTS 以及不同 budget；两两组合实验，用于比较 DDIM+TTS、CFG+TTS 的相互作用；三因素联合实验，用于比较 DDIM、CFG、TTS 同时开启时是否存在部署上更优的折中组合。

三层实验设计的逻辑是：单因素实验确认 TTS 本身的有效性和最优 budget 范围；两两组合实验检验 TTS 与其他优化手段之间是否存在交互效应；三因素联合实验给出面向实际部署的推荐配置。

\paragraph*{结果与分析}

在讨论具体数值前，需要先澄清一个容易混淆的概念层次，以避免``默认生成 8 条候选''与``TTS-8''发生语义重合。NoMaD 扩散策略头的每次前向本身会以批次形式并行生成若干条候选轨迹（本文固定为 8 条），这一批次规格由扩散头本身决定，与是否启用 TTS 无关。TTS 在此基础上额外引入两个正交的组件：一是候选池预算，当该预算超过单批候选数量时，通过多次扩散采样扩展候选池规模；二是评分筛选器，对池内候选按多目标评分排序，保留排名前 $k$ 的候选作为执行输出。因此，实验配置中的``未启用 TTS''与``TTS-8''都只触发一次扩散采样、生成同样的 8 条候选，差别只在于前者把候选集原样送入下游统计，后者多了一步基于评分的排序与前 $k$ 选择；而 TTS-16 和 TTS-32 则分别对应 2 次和 4 次扩散采样，用于真正扩展候选池规模。

TTS 实验围绕以下核心问题展开：是否值得把 DDIM 节省下来的计算预算重新分配给候选搜索，而不是要求 TTS 绝对提升所有指标。本实验在 12 组统一离线测试样例上比较 DDIM 步数、CFG 权重与 TTS 候选预算的组合，表~\ref{tab:tts-results} 给出在 DDIM-2、$w=0$ 条件下的单因素结果。

\subsection{视觉编码器升级实验}

\paragraph*{实验设计}

视觉编码器升级实验围绕以下问题展开：在统一训练和评价条件下，不同视觉编码器能否提供更有潜力的条件表征，以及这种表征差异主要体现在轨迹多样性、前进性、平滑性还是推理延迟上。

\paragraph*{候选编码器结构与对比}

本文在 EfficientNet-B0 之外纳入三类视觉骨干作为升级候选。DINOv2-Small\cite{dinov2_2023} 基于 Vision Transformer 架构，将图像切分为固定大小 patch 后送入 12 层 Transformer 编码器，参数量约 22\,M；自监督预训练赋予其较强的跨域泛化性，全局自注意力对远距离方向判断更敏感。ConvNeXt-Tiny\cite{convnext2022} 是借鉴 Transformer 设计原则的现代 CNN，采用更大卷积核、层归一化（Layer Normalization, LayerNorm）与更少激活函数，在保留 CNN 局部归纳偏置的同时提升表征能力，参数量约 28\,M。ResNet-50\cite{resnet2016} 作为经典残差 CNN 提供稳定基线，结构成熟、权重广泛可用，参数量约 25\,M。三者与 EfficientNet-B0 的 MBConv（5.3\,M）形成``自监督 ViT、现代 CNN、经典 CNN''的对照，覆盖表征机制与参数量两条对比维度。

\paragraph*{特征维度对齐}

四种编码器的原始输出维度并不一致：EfficientNet-B0 输出 1280 维，DINOv2-Small 输出 384 维，ConvNeXt-Tiny 输出 768 维，ResNet-50 输出 2048 维。为保证公平对比，本文在每个编码器输出端附加一个线性投影层，将原始特征统一映射到固定 token 维度 $d$：
\begin{equation}
\mathbf{z} = W_{\text{proj}} \cdot \mathbf{f}_{\text{enc}} + \mathbf{b}_{\text{proj}},
\end{equation}
其中 $\mathbf{z}$ 表示投影后的标准 token，$\mathbf{f}_{\text{enc}}$ 为编码器原始输出，$W_{\text{proj}} \in \mathbb{R}^{d \times d_{\text{enc}}}$ 为投影矩阵，$d$ 表示目标 token 维度，$d_{\text{enc}}$ 表示原始编码器输出维度，$\mathbf{b}_{\text{proj}}$ 为偏置向量。投影层与下游模块联合训练；投影后所有编码器在相同信息瓶颈下进入距离预测头与扩散策略头，避免条件空间容量差异干扰对比结果。


\paragraph*{训练配置}

在 GoStanford 数据集上对四种编码器分别进行 100 轮训练，批量大小设为 32，学习率与优化器配置统一。所有骨干网络参数参与微调，以便在相同训练轮数下最大化各编码器的适配空间。

\paragraph*{实验结果与分析}

四种编码器在相同离线测试样例、相同 DDPM-10 采样设置下的代理指标如表~\ref{tab:encoder-results} 所示。从指标分布看，各编码器在不同维度上表现各有侧重：ResNet-50 在轨迹多样性指标（0.9824）与前向进展指标（7.980）上最高，候选轨迹最分散、前进性最强；EfficientNet-B0 的平滑性指标最低（0.0725），原始基线在轨迹平滑性上仍具有优势；DINOv2-Small 与 ConvNeXt-Tiny 在三项质量指标上处于中段。延迟方面，四种编码器单次前向延迟均在 $34\text{--}37\,\text{ms}$ 区间，差异显著小于 DDIM 步数变化所带来的影响，因此编码器选择主要受表征质量约束而非延迟约束。

\subsection{优化方法之间的关系}

四种优化方法并不处在同一层级。视觉编码器升级位于视觉条件层，改变的是历史观察和目标图像进入模型后的特征表达；DDIM 与 CFG 位于扩散采样层，改变的是给定视觉条件后轨迹样本的生成方式；TTS 位于候选选择层，改变的是生成多条候选轨迹之后如何筛选最终执行轨迹。表~\ref{tab:optimization-role-summary} 总结了各方法的作用位置与实验含义。

        \toprule
        优化方法 & 作用层级 & 是否改变训练 & 阶段结论 \\

        DDIM & 扩散采样调度 & 否 & \texttt{DDIM-2} 默认最优，跨四编码器鲁棒 \\

因此，DDIM、CFG 与 TTS 更适合被写成统一推理层内部的层级组合：先由 DDIM 决定每条候选轨迹的去噪步数与生成速度，再由 CFG 决定采样过程中条件信号的放大程度，最后由 TTS 在候选轨迹集合上进行评分和选择。三者并不是简单并列相加，而是在``生成单条轨迹--增强条件响应--筛选候选轨迹''的流水线上依次发挥作用。算法~\ref{algo:inference-pipeline} 给出了四种优化方法在一次高层推理周期内的具体执行顺序，说明它们是如何在同一组观察输入上从``视觉表征—去噪采样—条件引导—候选筛选''逐层组合，最终输出一条供中层控制器跟踪的执行轨迹。

\begin{algorithm}[htb]
    \caption{统一推理模块在单次高层周期内的执行流程}
    \label{algo:inference-pipeline}
    \SetAlgoLined
    \KwIn{历史观察 $\mathcal{O}_t = \{I_{t-K},\ldots,I_t\}$，目标图像 $I_g$；视觉编码器权重 $\theta_{\text{enc}}$；DDIM 步数 $S$；CFG 权重 $w$；TTS 候选预算 $K$；扩散头每次前向产生的候选数 $N_0=8$}
    \KwOut{执行轨迹 $\mathbf{A}^\ast \in \mathbb{R}^{H\times 2}$}
    \BlankLine
    \tcp{1. 视觉编码器升级层：根据 $\theta_{\text{enc}}$ 提取 token，得到统一条件向量}
    $\mathbf{c} \leftarrow \text{VisionEncoder}_{\theta_{\text{enc}}}(\mathcal{O}_t, I_g)$\;
    $\mathbf{c}_\varnothing \leftarrow \text{VisionEncoder}_{\theta_{\text{enc}}}(\mathcal{O}_t, \text{mask})$\;
    \BlankLine
    \tcp{2. DDIM 采样层：用 $S$ 步 DDIM 一次性生成 $N_0$ 条候选轨迹}
    $M \leftarrow \lceil K / N_0 \rceil$\tcp*{扩散批次数；$K=N_0=8$ 时 $M=1$}
    $\mathcal{C} \leftarrow \emptyset$\;
    \For{$m \leftarrow 1$ \KwTo $M$}{
        $\mathbf{x}_S \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$，形状为 $N_0 \times H \times 2$\;
        \For{$s \leftarrow S$ \KwTo $1$}{
            \tcp{3. CFG 引导层：在每个去噪步同时执行条件与无条件分支并外推}
            $\boldsymbol{\epsilon}_{\text{cond}} \leftarrow \boldsymbol{\epsilon}_\theta(\mathbf{x}_s, s, \mathbf{c})$\;
            \uIf{$w \neq 0$}{
                $\boldsymbol{\epsilon}_{\text{uncond}} \leftarrow \boldsymbol{\epsilon}_\theta(\mathbf{x}_s, s, \mathbf{c}_\varnothing)$\;
                $\boldsymbol{\epsilon} \leftarrow (1+w)\boldsymbol{\epsilon}_{\text{cond}} - w\boldsymbol{\epsilon}_{\text{uncond}}$\;
            }
            \Else{
                $\boldsymbol{\epsilon} \leftarrow \boldsymbol{\epsilon}_{\text{cond}}$\;
            }
            $\mathbf{x}_{s-1} \leftarrow \text{DDIMStep}(\mathbf{x}_s, \boldsymbol{\epsilon}, s)$\;
        }
        $\mathcal{C} \leftarrow \mathcal{C} \cup \{\mathbf{x}_0^{(1)}, \ldots, \mathbf{x}_0^{(N_0)}\}$\tcp*{累积候选池}
    }
    \BlankLine
    \tcp{4. TTS 候选筛选层：对池内 $|\mathcal{C}|$ 条候选打分并取最优}
    \ForEach{$\mathbf{A}^{(i)} \in \mathcal{C}$}{
        $s_i \leftarrow \beta_1 \cdot \text{FP}(\mathbf{A}^{(i)}) - \beta_2 \cdot \text{LA}(\mathbf{A}^{(i)}) - \beta_3 \cdot \text{Smooth}(\mathbf{A}^{(i)})$\;
    }
    $\mathbf{A}^\ast \leftarrow \arg\max_{i} s_i$\;
    \Return $\mathbf{A}^\ast$\;
\end{algorithm}

算法~\ref{algo:inference-pipeline} 揭示了四种优化方法的层级关系：视觉编码器升级位于最外层，决定了条件向量 $\mathbf{c}$ 与 $\mathbf{c}_\varnothing$ 的特征分布；DDIM 步数 $S$ 控制中间去噪循环的长度，是单条候选轨迹生成成本的主要来源；CFG 权重 $w$ 在每一去噪步内通过条件/无条件外推增强目标响应，代价是每步多一次前向；TTS 预算 $K$ 决定候选池规模，当 $K=N_0=8$ 时只触发一次扩散批次（仅做评分排序），当 $K>N_0$ 时通过额外批次扩展候选池。本文最终采用的默认配置为 $S=2,\,w=0,\,K=8$，对应``两步 DDIM 采样一批 8 条候选 $\to$ 跳过 CFG 外推 $\to$ 直接对池内 8 条候选评分取最优''，这一组合在算法~\ref{algo:inference-pipeline} 的流程上把每一层的代价都压到最低，同时保留了多模态采样和评分筛选两项核心收益。

视觉编码器升级与前三者既相对独立，又存在间接联系。独立性体现在系统边界上：编码器替换只影响高层视觉表征模块，DDIM、CFG 和 TTS 主要作用于推理采样过程；只要模型保持 NoMaD 兼容输出，下游状态机和平台接口无需修改。联系则体现在条件分布上：更换编码器会改变历史观察和目标图像的 token 表达，从而同时影响距离预测头和扩散策略头。补齐后的编码器 $\times$ DDIM/TTS/CFG 联合消融（见表~\ref{tab:encoder-ddim-joint}--\ref{tab:encoder-cfg-joint}）给出的经验结论是：DDIM 步数选择与 CFG 权重选择对编码器替换具有鲁棒性，其中 DDIM-2 在四个编码器上都是默认最优档，CFG-1/2 在任何一个编码器上都无法换取有意义的质量增益；唯一与编码器耦合的是 TTS-8 的筛选增益——初始候选 Diversity 越高（如 ResNet-50），TTS-8 的相对提升越大。换言之，前三个优化中的``DDIM+CFG''部分在既定视觉条件空间内调整推理过程而不受编码器影响，TTS 部分则在一定程度上继承编码器带来的分布变化，视觉编码器升级则是在源头上改变条件空间。

\subsection{消融验证与编码器联合补充}

本章已经完成了主要算法变量的单因素消融和联合消融。DDIM 实验固定模型与测试样例，仅改变采样步数，验证了 \texttt{DDIM-2} 的速度收益与 \texttt{DDIM-1} 的失效边界；CFG 实验固定模型，仅改变引导强度，说明其质量收益不足以抵消默认开启时的时延代价；TTS 实验固定 DDIM 与 CFG 条件，比较不同候选预算，说明主要收益来自 TTS-8 的低成本筛选；视觉编码器实验在统一训练配置下比较四个训练权重，表明编码器替换框架具备训练、评估和接入闭环的可行性。

与 DDIM 的鲁棒性结论不同，表~\ref{tab:encoder-tts-joint} 揭示了一个编码器相关的规律：TTS-8 相对于 TTS-0 的前向进展增益幅度与初始多样性正相关。具体地，ResNet-50 的初始多样性为 0.943，TTS-8 将前向进展从 8.085 提升至 9.407（$+16.4\%$）；EfficientNet-B0 初始多样性为 0.611，TTS-8 增益为 $+9.5\%$；ConvNeXt-Tiny 初始多样性为 0.460，增益为 $+4.7\%$；DINOv2-Small 初始多样性为 0.390，增益为 $+6.0\%$。这一规律说明 TTS-8 对结果的增益依赖于扩散头生成候选时本身是否具有足够的多样性——初始多样性越高，基于多目标评分的前 $k$ 选择就越有可能在同一批 8 条候选中找出显著更好的子集。同时，平滑性指标和横向偏差指标也随 TTS-8 普遍下降，说明前 $k$ 选择不仅向前推进更远，还倾向于更平稳和更接近目标方向的候选。TTS-16 继续把这些指标往同一方向推进，但其代价是时延翻倍（从约 5.5\,ms 增至约 10.7--11.0\,ms）。因此``TTS-8 作为默认档位、TTS-16 作为可选增强''的部署建议在四个编码器上均成立。

由表~\ref{tab:encoder-cfg-joint} 可以看出：在这两个初始 Diversity 差异最大的编码器上，CFG-1/2 对 Forward Progress 的提升都在 $1\%$ 以内，而时延无一例外地翻倍——CFG 开启需要一次条件分支与一次无条件分支的额外前向。以 EfficientNet-B0 为例，CFG 从 0 增至 2 时 Forward Progress 仅由 8.290 上升至 8.363，同时 Lateral Abs 从 2.361 增至 3.226（横向偏摆放大了近 $37\%$），Diversity 从 0.611 压缩到 0.434；换言之，CFG 的外推方向对 EfficientNet-B0 的候选分布有``收紧加放大偏摆''的双重扰动。ResNet-50 的反应更平淡：它所有指标在 CFG=0/1/2 之间几乎保持不变，Diversity 从 0.943 仅微降到 0.940，Forward Progress 和 Smoothness 的变化都在 CI95 之内。这一对比说明：CFG 对编码器差异既没有``放大优势''也没有``补偿劣势''，反而使原本 Diversity 较低、结构较紧的 EfficientNet-B0 受到更明显的分布扰动。综合两个编码器的结果，本文原先得到的``默认 CFG=0''结论得到了进一步验证。

三组联合消融实验共同说明，DDIM 步数选择对编码器替换鲁棒，TTS 筛选收益随候选多样性放大，CFG 引导则在本文视觉条件空间内缺乏明显增益。因此，最终算法框架确定一节推荐的``EfficientNet-B0 + DDIM-2 + CFG=0 + TTS-8''默认方案在跨编码器视角下仍然成立。

\subsection{最终算法框架确定}

综合本章的全部离线实验，本文将最终算法框架确定为：EfficientNet-B0 视觉编码器、DDIM-2 采样、CFG=0、TTS-8。这一组配置随后被提炼为系统层的``统一推理模块''：在第~\ref{sec:unified-arch} 节定义的分层架构中，模型权重、采样器类型、采样步数、引导强度和候选预算被统一管理，而算法~\ref{algo:inference-pipeline} 描述的执行顺序则成为该模块对外提供的标准推理流程。换言之，本章实验的目的不是给出一组孤立的最佳数值，而是确定推理模块在部署侧应当采用的默认设置与执行模板，使下游状态机、导航主机和平台后端能够复用同一套高层推理流程。

为了适配不同部署需求，可在该默认配置之上给出三个候选层级。低时延默认方案与上述最终配置一致，是统一推理模块的默认方案；稳定方案将 DDIM 步数提高到 3 或 5，并保持 CFG=0 与 TTS-8，用于对推理时延不敏感、对轨迹光滑性要求更高的场景；复杂场景增强方案在默认配置上额外引入较高的 CFG 权重或更大的 TTS 候选预算，用于强目标牵引或更激进的候选筛选。三种层级共享同一推理模块接口，差别仅在推理设置的选择。视觉编码器升级实验的价值则在于建立``可替换、可重训、可评测''的编码器训练与评估框架，并发现潜在的视觉编码器替换候选，而不是直接说明 DINOv2 或 ResNet-50 已经全面优于原始的 EfficientNet-B0；该框架对后续章节的系统集成保持透明。

\section{本章小结}

本章围绕统一视觉目标导航推理模块展开研究。首先从 MDP 视角对视觉导航任务进行了形式化建模，分析了条件轨迹分布与传统策略的联系，并论证了航点表示在平台无关性、多模态表达和闭环控制方面的优势。其次，以 NoMaD 为基础梳理了视觉编码器架构、token 构建过程、训练目标和统一推理接口。在此基础上，以基线实验为参照，对 DDIM 推理加速、CFG 引导增强、TTS 推理时搜索和视觉编码器升级进行了系统分析。
