\chapter{算法设计与实验}

\section{任务定义与研究思路}

本文关注的核心任务是：给定机器人当前视觉观察、短历史观察和目标图像，生成一段局部 waypoint 轨迹，并将其作为中层控制器的参考输入。沿用 NoMaD 的基本思想\cite{nomad2023}，本方法不直接预测单步速度命令，而是学习条件轨迹分布
\begin{equation}
p(\mathbf{A}_t \mid \mathcal{O}_t, I_g),
\end{equation}
其中 $\mathcal{O}_t$ 表示时刻 $t$ 的历史视觉观察，$I_g$ 表示当前控制周期使用的目标图像，在拓扑导航中是 topomap 序列上``当前定位的下一节点''图像，$\mathbf{A}_t$ 表示未来局部 waypoint 序列。

\subsection{问题建模}

从马尔可夫决策过程（Markov Decision Process, MDP）的视角来看，视觉导航可以被建模为一个元组 $\mathcal{M} = (\mathcal{S}, \mathcal{A}, T, R, \gamma)$，其中 $\mathcal{S}$ 表示状态空间（即视觉观察空间），$\mathcal{A}$ 表示动作空间，$T$ 表示转移概率，$R$ 表示奖励函数，$\gamma$ 表示折扣因子。在本文的框架中，策略 $\pi$ 不是直接在 MDP 上求解单步最优动作，而是学习一个条件轨迹分布 $p(\mathbf{A}_t \mid \mathcal{O}_t, I_g)$，这种分布式策略具有天然的多模态建模能力。

具体来说，条件轨迹分布与传统 MDP 策略之间的联系可通过以下关系理解：若将未来 $H$ 步动作序列视为一个联合决策变量，则条件轨迹分布相当于在扩展动作空间 $\mathcal{A}^H$ 上的策略。与逐步递推不同，这种联合建模能够在单次推理中捕获全局轨迹结构，避免了自回归策略中误差累积的问题。形式上：
\begin{equation}
p(\mathbf{A}_t \mid \mathcal{O}_t, I_g) = p(\mathbf{a}_1, \mathbf{a}_2, \ldots, \mathbf{a}_H \mid \mathcal{O}_t, I_g),
\end{equation}
其中每个 $\mathbf{a}_i$ 并非独立采样，而是通过扩散过程的联合去噪一次性生成。

这种建模方式与经典的行为克隆（Behavioral Cloning）策略存在本质区别。行为克隆通常将策略参数化为确定性映射 $\pi_\theta: \mathcal{O} \to \mathcal{A}$ 或简单的高斯分布，只能表达单峰的动作分布。而基于扩散模型的条件生成策略通过迭代去噪过程，能够从复杂的多模态分布中采样，天然适合处理导航任务中的分支决策场景。此外，扩散模型的训练目标（噪声预测损失）在数值上比最大似然目标更稳定，不容易出现模式坍塌（mode collapse）问题。

\subsection{Waypoint 表示的优势分析}

本文选择 waypoint 序列作为策略输出形式，而非直接预测底层速度命令（如线速度 $v$ 和角速度 $\omega$），这一设计决策基于以下三点考量。

第一，平台无关性。Waypoint 表示为局部坐标系下的二维位移序列，不与任何特定的运动学模型绑定。无论下游执行平台是差分驱动的轮式机器人还是具有复杂运动学的足式机器人（如 Lite3），同一条 waypoint 轨迹都可以通过不同的中层控制器进行跟踪。这种解耦使得高层策略的训练数据可以跨平台复用。

第二，多模态表达能力。在面对 T 形路口或走廊分叉等场景时，合理的导航行为可能包含``左转''和``右转''两个互不相容的模态。若使用单步速度命令的均值回归策略，两个模态的平均结果可能是``直行撞墙''。而 waypoint 序列结合扩散模型的生成能力，能够保留这种多模态分布，通过采样不同轨迹来表达不同的决策意图。

第三，闭环控制的友好性。中层控制器（如 PID 或 MPC）可以直接将 waypoint 序列作为参考路径进行跟踪，这比将高层策略输出的速度命令直接下发到底层更加鲁棒，因为 waypoint 跟踪器可以根据实际执行情况进行局部修正。

waypoint 序列还提供了比单步动作更丰富的决策信息。单步速度命令仅编码了当前时刻的瞬时意图，而 waypoint 序列编码了未来一段时间窗口内的完整运动意图。这种``前瞻性''信息对于中层控制器的预测性规划至关重要——控制器可以提前预判即将到来的转弯或减速需求，从而生成更平滑的底层控制信号。特别是对于足式机器人，步态切换和身体姿态调整需要提前规划，单步速度命令无法提供足够的前瞻信息。

围绕这一任务，本文在算法层的工作可概括为三部分。第一，基于项目代码准确复现 NoMaD 的训练与推理链路，明确视觉编码器、距离预测头与扩散策略头之间的关系。第二，围绕部署可用性对推理层进行优化，重点研究 DDIM 推理、CFG 引导增强和 TTS 推理时搜索。第三，围绕视觉表征能力设计视觉编码器升级实验，并与基线配置进行对比。需要强调的是，本章关注的是``哪些候选方法值得进入闭环验证''，因此所有结论都首先被限定在离线统计与离线代理指标层面。

\section{NoMaD 基础模型复现}

\subsection{输入输出形式}

根据当前项目配置，NoMaD 的输入由历史视觉观察与目标图像构成。实验中设置为 \texttt{context\_size=3}，即模型同时接收三张历史观察帧与一张目标图像。输出则为固定长度的局部轨迹序列，每个 waypoint 用局部坐标系下的二维位移表示：
\begin{equation}
\mathbf{a}_i = (\Delta x_i, \Delta y_i), \qquad i=1,\ldots,H.
\end{equation}
整段轨迹写为
\begin{equation}
\mathbf{A} = [\mathbf{a}_1,\mathbf{a}_2,\ldots,\mathbf{a}_H].
\end{equation}

这一表示的优点在于，它比直接输出底层速度命令更适合作为平台无关的高层接口，也比全局路径更适合闭环局部控制。对于足式平台，高层输出局部轨迹、中层完成控制映射的方式尤为关键。

\subsection{视觉编码器架构}

NoMaD 默认采用 EfficientNet-B0 作为视觉编码器骨干\cite{efficientnet2019}。EfficientNet-B0 是 EfficientNet 系列的基础模型，通过复合缩放（compound scaling）策略在深度、宽度和分辨率三个维度上进行统一缩放，在 ImageNet 上以约 5.3\,M 参数量达到了优异的精度-效率平衡。其核心构建块为 MBConv（Mobile Inverted Bottleneck Convolution），采用深度可分离卷积和 Squeeze-and-Excitation 注意力模块。

NoMaD 实现中，\texttt{NoMaD\_ViNT} 内部实例化了两个 EfficientNet-B0：一个只处理单帧观察（3 通道输入），另一个处理``最后一帧观察 + 目标图像''的 6 通道拼接输入。二者权重独立、架构几乎相同，只在输入卷积的通道数上有差别。这一设计使得目标分支在特征层就完成了当前帧与目标帧的早期融合，但也使得视觉编码器部分的参数量近似等于两个 EfficientNet-B0 之和，再加上一个输出投影层（将 1280 维 backbone 特征压缩到 256 维 token 维度）。

两个 EfficientNet-B0 接收 $96 \times 96$ 的 RGB 图像作为输入，提取特征后分别输出一个固定维度的视觉表示。该特征向量随后被投影为标准化的 token 表示，用于后续的条件拼接。具体而言，每帧观察图像经过第一个编码器后得到特征 $\mathbf{z}_i \in \mathbb{R}^d$，其中 $d$ 为 token 维度（本文配置下 $d=256$）；目标 token $\mathbf{z}_g$ 由第二个编码器以相同方式得到。

选择 EfficientNet-B0 而非更大的 EfficientNet 变体（如 B3 或 B5）是出于推理效率的考虑。在边缘设备上，视觉编码器的计算开销直接影响整体推理频率，而 B0 的 5.3\,M 参数量在精度与效率之间提供了合理的折中；由于 NoMaD 中需要同时维护两个 EfficientNet-B0 实例，骨干规模的选择对整体部署时延具有放大效应，这进一步佐证了 B0 作为默认选型的合理性。

\subsection{Token 构建与条件拼接}

NoMaD 的视觉条件编码器 \texttt{NoMaD\_ViNT} 由两个相互独立的 EfficientNet-B0 实例组成：一个为观察编码器 \texttt{obs\_encoder}，输入 3 通道单帧图像，用来独立编码每一个历史观察帧；另一个为目标编码器 \texttt{goal\_encoder}，输入 6 通道图像，其输入是将当前帧（即观察窗口的最后一帧）与目标图像沿通道维度拼接而成。这样设计的原因是目标 token 天然需要同时携带``当前在哪''和``要去哪''两种信息，因此在特征提取层就进行早期融合能减轻后续 self-attention 的负担。

对于 \texttt{context\_size=3} 的配置，模型一次前向会产生四个 token：由 \texttt{obs\_encoder} 独立编码的三个观察 token $[\mathbf{z}_{t-2}, \mathbf{z}_{t-1}, \mathbf{z}_t]$，以及由 \texttt{goal\_encoder} 编码的一个融合了当前帧与目标图像的目标 token $\mathbf{z}_g$。四个 token 经位置编码后送入 Transformer self-attention encoder，再对所得序列做掩码加权平均池化，得到固定维度的视觉条件向量：
\begin{equation}
\mathbf{c} = \text{AvgPool}\bigl(\text{SA}\bigl([\mathbf{z}_{t-2}, \mathbf{z}_{t-1}, \mathbf{z}_t, \mathbf{z}_g]\bigr)\bigr).
\end{equation}
这一条件向量同时作为距离预测头和扩散策略头的输入。

需要特别说明的是，NoMaD 通过目标掩码（goal mask）实现导航模式与探索模式的切换。当 goal mask 取 0 时，目标 token $\mathbf{z}_g$ 正常参与 self-attention，模型处于``带目标导航''模式；当 goal mask 取 1 时，$\mathbf{z}_g$ 所在位置被置为 padding 并在池化时去掉权重，模型退化为``无目标探索''模式。这一机制使得同一套权重既可用于导航也可用于探索，也是后续 CFG 引导能同时使用``带目标''与``不带目标''两次前向的直接原因。

\subsection{模型结构与训练目标}

NoMaD 由视觉编码器、距离预测头和扩散策略头三部分组成\cite{nomad2023}。视觉编码器负责将历史观察与目标条件编码为统一特征；距离预测头输出当前观察到目标的相对距离估计；扩散策略头在该条件上生成局部轨迹样本。

训练时，总损失由距离回归损失与扩散噪声预测损失组成，可写为
\begin{equation}
\mathcal{L} = \alpha \mathcal{L}_{dist} + (1-\alpha)\mathcal{L}_{diff}.
\end{equation}
其中，$\mathcal{L}_{dist}$ 约束候选目标排序能力，$\mathcal{L}_{diff}$ 约束局部轨迹生成质量。

关于损失权重 $\alpha$ 的选择策略，需要注意以下两点。首先，$\mathcal{L}_{dist}$ 通常采用 $L_1$ 或 $L_2$ 回归损失，其数值尺度与扩散噪声预测损失 $\mathcal{L}_{diff}$ 存在差异，因此 $\alpha$ 实际上同时承担了任务权重和尺度归一化的双重角色。其次，距离预测头的梯度会回传至视觉编码器，这意味着 $\alpha$ 的选择会影响编码器学到的特征偏向——较大的 $\alpha$ 倾向于让编码器学习距离敏感的特征，较小的 $\alpha$ 则让编码器更侧重于轨迹生成所需的空间结构特征。

距离预测头与视觉编码器是直接耦合的，因此更换视觉编码器后，距离预测分支必须同步重新训练，否则距离头与轨迹头将共享不一致的条件分布。

\subsection{推理链路的统一封装}

在推理阶段，系统先编码观察与目标，再在需要时进行候选节点距离评估，最后通过扩散采样生成轨迹。

统一推理模块的设计遵循``配置驱动''原则：所有推理行为由一组配置参数完全确定，不存在隐式的硬编码默认值。这使得后续的 DDIM、CFG 和 TTS 实验可以通过修改配置文件来切换，而不需要改动推理代码本身。同时，统一推理模块也提供了标准化的输出接口，包括候选轨迹集合、距离预测值和推理时间统计，方便下游的评估脚本和闭环系统直接使用。

\section{数据集与实验设备}

\subsection{GoStanford 数据集}

本文所有离线实验均基于 GoStanford数据集进行。该数据集来源于斯坦福大学校园环境中通过自主采集机器人记录的视觉导航轨迹，是 NoMaD 项目使用的标准训练与评估数据来源之一\cite{gnm2022,vint2023,nomad2023}。数据集中的每条轨迹包含按时间顺序排列的第一人称 RGB 图像帧和对应的位姿信息。

GoStanford 数据集的场景多样性是其作为标准评估数据集的重要优势。数据采集覆盖了斯坦福大学校园中的室内走廊、室外道路、建筑入口、停车区域等多种环境类型。每条轨迹的长度从几十帧到数百帧不等，对应数十米到数百米的实际行驶距离。图像帧的采集频率约为 4\,Hz，位姿信息由里程计或 GPS 提供，精度足以用于轨迹级别的训练监督。

本文使用的本地数据集包含来自 GoStanford 的多条轨迹。在离线实验中，每次推理从轨迹中提取连续观察帧与目标帧，构建标准化测试 case。DDIM、CFG 与编码器实验使用 24 个 case；TTS 补充实验为控制组合规模使用 12 个 case，但保持相同的 case 构造规则和统计口径。

\subsection{数据预处理流程}

从原始轨迹到模型输入之间存在一个标准化的数据预处理流程。首先，RGB 图像从原始分辨率（通常为 $640 \times 480$）对齐至模型要求的输入尺寸（$96 \times 96$），缩放过程使用双线性插值。其次，像素值从 $[0, 255]$ 归一化至 $[0, 1]$ 范围。最后，根据 \texttt{context\_size} 参数从轨迹中提取连续帧作为历史观察，并从同一轨迹的未来位置选取目标帧。

测试 case 的构建遵循以下原则：当前观察与目标帧之间的时间间隔覆盖短距离（5--10 帧）和中距离（20--50 帧）两种范围，以确保评估涵盖不同难度级别。每个 case 包含完整的历史观察序列、目标图像和对应的真实轨迹标签，使得所有实验在完全相同的数据条件下进行比较。

值得说明的是，24 个测试 case 的数量虽然有限，但其设计覆盖了直行、转弯、宽阔区域和狭窄走廊等多种典型场景类型。在离线统计实验中，这一规模足以反映不同配置之间的趋势性差异，同时保持单次完整实验的运行时间在可接受范围内。对于需要更高统计置信度的结论，本文通过报告 CI95 来量化均值估计的不确定性。

\subsection{感知输入与设备说明}

本文系统采用纯 RGB 单目视觉作为唯一感知输入，不依赖深度传感器、激光雷达或惯性测量单元。这一设计选择与 NoMaD 原始框架一致，即高层导航策略仅以图像观察和目标图像为输入，不需要额外传感模态。

纯视觉感知的优势在于硬件成本低、安装简单、且与人类的导航感知方式最为接近。其主要局限在于：（1）缺乏显式的深度信息，无法直接判断障碍物距离；（2）对光照变化和动态遮挡敏感；（3）单目视觉的尺度模糊性使得绝对距离估计困难。NoMaD 通过学习大量导航轨迹数据来隐式弥补这些局限。

在离线实验阶段，训练与统计实验运行在配备 NVIDIA RTX 4090 的计算机上；在 MuJoCo 仿真阶段，相机图像由 MuJoCo 渲染器以第一人称视角生成；在真机部署阶段，使用 USB 单目相机接入 Jetson Orin，输出分辨率为 $640\times480$。

RTX 4090 与 Jetson Orin 之间的算力差距是本文实验设计中需要特别关注的因素。RTX 4090 适合承担离线训练和统计实验，而 Jetson Orin 属于机载边缘计算平台，受功耗、散热和统一内存资源约束更强。这意味着在 RTX 4090 上可接受的推理时延，在 Jetson Orin 上仍需要通过板端 benchmark 重新确认。因此，本文在离线实验中特别关注时延指标的绝对值而非仅关注相对加速比，以便为部署阶段的配置选择提供直接参考。

\section{基线实验}

为给后续所有优化实验建立统一参考，本文首先复现了原始 NoMaD 离线推理流程。输出结果表明，原始模型参数量约为 19,049,675。需要区分两种不同口径的时延：在端到端单次运行中，包含图像加载、编码、DDPM-10 采样与结果后处理的整体耗时约为 0.1250\,s；而在本章后续使用的 24 个 case 统计实验中（见表~\ref{tab:ddim-results}），\texttt{ddpm\_10} 的纯扩散采样平均时延约为 40\,ms，CI95 为 $\pm$1.37\,ms。两者数量级差异的根本原因是前者计入了一次性模型构建、首次 GPU kernel 编译与图像预处理开销，而后者在 warm-up 之后测量循环体内部的推理时间。由于后续 DDIM、CFG、TTS 与视觉编码器对比实验都运行在统一的统计脚本下，本文把``40\,ms 量级''视为基线推理时延的有效参考，而把``0.125\,s''仅保留作单次端到端流程的工程记录。

关于参数量的构成，19.05\,M 参数中视觉条件编码器约占 15.18\,M（含两个 EfficientNet-B0、投影层、位置编码与 4 层 self-attention），扩散策略头（ConditionalUnet1D）约占 3.85\,M，距离预测头约占 0.02\,M。由此可见视觉编码器是主要参数来源，更换视觉编码器对总参数量的影响取决于新骨干的规模：若替换为 DINOv2-Small（22\,M backbone）或 ConvNeXt-Tiny（27\,M backbone）将使总参数量明显上升；若保持 backbone 在 B0 量级则总参数量相近。

扩散策略头中的 U-Net 架构采用了多尺度特征融合和条件注入机制。条件向量 $\mathbf{c}$ 通过 FiLM（Feature-wise Linear Modulation）机制注入到 U-Net 的各个分辨率层级中，使得噪声预测网络能够在每一步去噪中都感知到当前的视觉条件和目标信息。这种设计虽然增加了参数量，但保证了扩散过程对条件信号的充分响应。

关于推理频率的部署含义，40\,ms 的纯采样时延在 RTX 4090 上对应约 25\,Hz 的理论上限，但叠加图像预处理、消息传递或可视化后，端到端频率通常会明显低于该理论值。在边缘设备（如 Jetson Orin）上，实际频率还会受到功耗模式、散热状态、相机驱动和 PyTorch/CUDA 版本影响，因此不能仅按桌面 GPU 与边缘 GPU 的标称算力比例线性外推。本文把 DDIM 加速作为部署优化的直接动机，但具体真机可用频率以后续 Orin 阶段 benchmark 为准。

此外，$8 \times 8$ 的轨迹采样规格表示每次推理生成 8 条候选轨迹，每条轨迹包含 8 个 waypoint。8 个 waypoint 的长度在默认配置下对应约 2--3 秒的未来规划窗口，这一时间尺度既足以覆盖局部导航决策（如是否转弯），又不至于因规划太远而积累过大误差。

\section{实验指标与统计原则}

为了避免仅凭单次样本或单一指标做结论，本文采用多指标联合分析。主要指标包括：Latency，用于衡量推理开销；CI95，用于表示均值的 95\% 置信区间；MSE vs DDPM-10，用于衡量与基线采样分布的偏移；Forward Progress，用于刻画轨迹在主前进方向上的推进程度；Lateral Abs，用于衡量横向偏摆幅度；Smoothness，用于衡量轨迹变化的平滑性；Dist Pred Mean，用于观察候选目标距离评估是否随条件空间变化发生系统偏移。

\subsection{指标的形式化定义}

为确保实验可复现性，本文给出各指标的形式化定义。

\textbf{Latency} 定义为单次推理的端到端耗时，包含编码、去噪和后处理，单位为毫秒：
\begin{equation}
\text{Latency} = t_{\text{end}} - t_{\text{start}}.
\end{equation}

\textbf{CI95} 表示均值的 95\% 置信区间半径，基于 $t$ 分布计算：
\begin{equation}
\text{CI95} = t_{0.975, n-1} \cdot \frac{s}{\sqrt{n}},
\end{equation}
其中 $s$ 为样本标准差，$n$ 为测试 case 数量。

\textbf{MSE vs DDPM-10} 衡量某配置生成轨迹均值与基线 DDPM-10 生成轨迹均值之间的均方误差：
\begin{equation}
\text{MSE} = \frac{1}{H} \sum_{i=1}^{H} \|\bar{\mathbf{a}}_i^{\text{test}} - \bar{\mathbf{a}}_i^{\text{base}}\|^2,
\end{equation}
其中 $\bar{\mathbf{a}}_i$ 表示第 $i$ 个 waypoint 在所有候选轨迹上的均值。

\textbf{Forward Progress} 定义为轨迹在主前进方向（$x$ 轴）上的累计位移：
\begin{equation}
\text{FP} = \sum_{i=1}^{H} \Delta x_i.
\end{equation}

\textbf{Lateral Abs} 定义为轨迹在横向（$y$ 轴）上的累计绝对位移：
\begin{equation}
\text{LA} = \sum_{i=1}^{H} |\Delta y_i|.
\end{equation}

\textbf{Smoothness} 衡量相邻 waypoint 之间方向变化的一致性，定义为相邻位移向量差的范数均值：
\begin{equation}
\text{Smooth} = \frac{1}{H-1} \sum_{i=1}^{H-1} \|\mathbf{a}_{i+1} - \mathbf{a}_i\|.
\end{equation}

\subsection{统计显著性与多指标分析原则}

本文采用多指标联合分析而非单一指标排序，原因在于导航任务的优化目标本质上是多目标的。仅优化前进性可能导致激进轨迹，仅优化平滑性可能导致过于保守的运动。通过同时报告 Forward Progress、Lateral Abs、Smoothness 和 Latency，可以判断某个配置是否在所有维度上都可接受，而不是在某一维度上表现突出但在其他维度上严重退化。

在统计检验层面，由于本文的离线实验样本量为 24 个 case，属于小样本范畴。对于小样本比较，本文主要依赖 CI95 的重叠程度来判断差异的显著性：若两个配置的 CI95 不重叠，则认为差异具有统计意义；若 CI95 部分重叠，则需结合效应量大小（即均值差与标准差之比）进行综合判断。这种方法比直接进行 $p$ 值检验更适合本文的实验规模和多次比较场景。

其中，CI95 并不是新的性能指标，而是均值稳定性的统计描述。若某个配置平均值较优但 CI95 很宽，说明其结果在不同 case 间波动较大。Forward Progress 也不能单独解释为越大越好，因为过大的前进量可能是激进采样带来的分布偏移，必须结合 MSE、Lateral Abs 和 Smoothness 一起分析。

\section{DDIM 推理加速实验}

\subsection{理论动机}

DDIM 的核心思想是将扩散模型的随机微分方程（SDE）采样过程转换为确定性常微分方程（ODE）求解过程\cite{ddim2020}。在标准 DDPM 中，反向去噪过程由以下随机递推描述：
\begin{equation}
\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left(\mathbf{x}_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)\right) + \sigma_t \mathbf{z},
\end{equation}
其中 $\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 引入了随机性。DDIM 的关键洞察是：当令随机项 $\sigma_t = 0$ 时，上述过程退化为确定性的 ODE 积分：
\begin{equation}
\mathbf{x}_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \cdot \hat{\mathbf{x}}_0(\mathbf{x}_t, t) + \sqrt{1-\bar{\alpha}_{t-1}} \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t),
\end{equation}
其中 $\hat{\mathbf{x}}_0$ 是基于当前噪声预测的干净样本估计。

由于 ODE 的解路径是确定性的且连续的，可以在时间轴上使用更大的步长进行积分而不引入额外随机噪声的累积。这就是 DDIM 能够用更少步数完成去噪的数学基础——本质上是用粗粒度的数值积分近似原始的细粒度 ODE 轨迹。步数越少，积分越粗糙，但对于 smooth 的 ODE 解路径，适度的步数减少不会显著改变最终结果。

从数值分析的角度，DDIM 的步数减少可以类比为 ODE 求解器中步长的增大。对于一阶 Euler 方法，截断误差与步长 $h$ 成正比；而 DDIM 的更新规则实际上对应一种隐式的高阶积分格式，因此在步数适度减少时能保持较小的截断误差。但当步数降至极端（如仅 1 步）时，单步积分的假设不再成立，误差会急剧增大。

\subsection{实验设计}

DDIM 的作用是在不重新训练模型的情况下减少扩散去噪步数，从而降低推理时延\cite{ddim2020}。本文以\texttt{ddim\_x}来定义采用DDIM采样 x 步的配置。本文在统一脚本下比较 \texttt{ddpm\_10}、\texttt{ddim\_10}、\texttt{ddim\_5}、\texttt{ddim\_3}、\texttt{ddim\_2} 和 \texttt{ddim\_1} 六种配置，测试集共包含 24 个 case。该实验的目标是回答两个问题：第一，步数减少后推理能快多少；第二，轨迹分布是否仍保持在可接受范围。

六种配置的选择覆盖了相比于基线，从``不减少步数''到``极端压缩至单步''的完整频谱。\texttt{ddim\_10} 与 \texttt{ddpm\_10} 步数相同，用于验证 DDIM 在不减步时是否引入额外偏差；\texttt{ddim\_5} 和 \texttt{ddim\_3} 代表中等程度的加速；\texttt{ddim\_2} 代表较为激进但仍可控的加速；\texttt{ddim\_1} 则代表理论极限，用于探测 DDIM 的失效边界。这种全频谱设计使得本文能够精确定位速度与质量的平衡点。

\section{CFG 引导增强实验}

\subsection{理论分析}

Classifier-Free Guidance（CFG）的核心思想是在推理时通过线性外推来增强条件信号对生成结果的影响\cite{cfg2022}。具体来说，CFG 修改了扩散模型的噪声预测（score function）为：
\begin{equation}
\tilde{\boldsymbol{\epsilon}}_\theta(\mathbf{x}_t, t, \mathbf{c}) = (1+w) \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \mathbf{c}) - w \cdot \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \varnothing),
\end{equation}
其中 $\mathbf{c}$ 为条件向量（包含观察和目标信息），$\varnothing$ 表示空条件（训练时通过随机 dropout 条件实现），$w$ 为引导权重。

当 $w=0$ 时，退化为标准的条件采样；当 $w>0$ 时，生成结果在条件方向上被``放大''，使轨迹更强烈地朝向目标方向偏移；当 $w<0$ 时，则产生反向引导效果。从概率密度的角度，CFG 实质上是在对数概率空间中将条件分布与无条件分布的差异进行缩放：
\begin{equation}
\log \tilde{p}(\mathbf{x} \mid \mathbf{c}) \propto (1+w) \log p(\mathbf{x} \mid \mathbf{c}) - w \log p(\mathbf{x}).
\end{equation}
这意味着 $w$ 越大，生成分布越集中于条件分布的高概率区域，同时远离无条件先验的模态。

\subsection{实验设计}

CFG 的目标是在推理阶段增强轨迹对目标条件的响应\cite{cfg2022}。本文选取 $w\in\{-1.0,0.0,0.5,1.0,2.0,4.0\}$ 六组配置进行比较。实验探索最佳的引导强度的数值，能够在目标牵引与分布稳定性之间取得平衡。

负值引导（$w=-1.0$）被包含在实验中，目的是验证反向引导是否会导致轨迹偏离目标方向。如果 $w=-1.0$ 的 Forward Progress 显著低于 $w=0.0$，则说明 CFG 的条件引导方向确实与目标方向一致，从而间接验证了 CFG 机制在导航任务中的有效性。

\subsection{实验结果与分析}

结果表明，适度的 CFG 能提高轨迹对目标方向的响应，但代价是更高的推理时延和潜在的分布偏移。从表~\ref{tab:cfg-results} 可以看到，$w=0.0$ 时推理时延约为 42.65\,ms，而 $w \geq 0.5$ 后时延跃升至约 78--80\,ms，这是因为 CFG 需要同时执行条件分支与无条件分支的噪声预测。CFG 的每一步去噪都需要对噪声预测网络进行两次前向传播——一次使用完整条件 $\mathbf{c}$，一次使用空条件 $\varnothing$——然后将两次预测结果进行线性组合。因此，CFG 的计算成本近似为非 CFG 推理的 2 倍。实验中 $w=0.0$ 到 $w=0.5$ 的时延跳变（42.65\,ms $\to$ 78.27\,ms）正好反映了这一理论预期。

在轨迹质量方面，$w=1.0$ 的 Forward Progress 最高（8.573），Lateral Abs 仍保持适度（2.901），说明该配置在前进性和稳定性之间表现较为均衡。而 $w=4.0$ 时 Shift 高达 0.5133，Lateral Abs 上升至 3.089，表明过强的引导会导致分布偏移与横向偏摆。

关于最优引导尺度的选择，本文认为应遵循以下准则：（1）引导强度不应使 Shift 指标超过 0.2，以避免显著的分布偏移；（2）在满足（1）的前提下，优先选择 Forward Progress 较高的配置；（3）必须考虑时延代价——如果 CFG 带来的质量提升不能补偿 2 倍时延的代价，则不建议开启。

从实验数据来看，$w=-1.0$ 的反向引导在 Shift 和 Forward Progress 上与 $w=0.0$ 差异极小，说明轻微的反向引导对轨迹分布的影响可以忽略。$w=0.5$ 和 $w=1.0$ 的 Shift 分别为 0.0160 和 0.0476，均在 0.2 的阈值以内，属于可接受范围。$w=2.0$ 的 Shift 为 0.1438，虽未超过阈值但已接近边界，提示进一步增大引导可能带来不稳定性。综合以上分析，本文将 CFG 定位为可调部署旋钮，而非必须开启的固定默认项。

\section{TTS 推理时搜索实验}

\subsection{实验设计}

TTS 的作用是把额外预算用于``候选生成与选择''，而非用于修改训练过程\cite{ttsdiffusion2025,ttssearch2025}。在本文中，TTS 被设计为推理层的外层搜索组件：先用当前采样配置生成多条候选轨迹，再根据目标一致性、前进性和平滑性综合打分，最终选择一条更适合执行的轨迹。实验重点比较不同预算下的轨迹质量收益，以及它与 DDIM、CFG 的组合关系。

\subsection{评分函数设计}

TTS 的核心在于评分函数的设计。本文采用加权多目标评分函数：
\begin{equation}
\text{Score}(\mathbf{A}) = \beta_1 \cdot \text{FP}(\mathbf{A}) - \beta_2 \cdot \text{LA}(\mathbf{A}) - \beta_3 \cdot \text{Smooth}(\mathbf{A}),
\end{equation}
其中 $\text{FP}$ 为前进性，$\text{LA}$ 为横向绝对偏摆，$\text{Smooth}$ 为平滑性代价，$\beta_1, \beta_2, \beta_3$ 为权重系数。

评分函数中权重系数的选择需要根据具体部署场景进行调整。在开阔环境中，可以增大 $\beta_1$ 以鼓励更积极的前进；在狭窄走廊中，应增大 $\beta_2$ 以抑制横向偏摆；在需要精细控制的场景中，$\beta_3$ 应占主导以保证轨迹平滑性。本文在离线实验中采用固定权重配置，但在部署阶段可以根据场景类型动态调整。

\subsection{计算预算分配策略}

TTS 的计算开销与候选轨迹数（budget）总体正相关。设单次采样耗时为 $\tau$，则 TTS-$K$ 的总耗时可近似表示为候选生成开销与评分开销之和，其中评分与排序通常只占很小比例。由于实际实现会复用批量张量计算，耗时不会严格等于 $K \cdot \tau$。因此，DDIM 加速节省的时间预算可以部分重新分配给 TTS，形成``用更快的单次采样换取更多候选''的策略。

这种预算分配思路可以形式化为一个受约束的优化问题：在总时延预算 $T_{\max}$ 的约束下，选择 DDIM 步数 $S$ 和 TTS budget $K$ 以最大化轨迹质量。由于 $K \cdot \tau(S) \leq T_{\max}$，减少 $S$（加速单次采样）就能增大 $K$（增加候选数量），两者之间存在自然的折中关系。

\subsection{实验组织方式}

为了保证结论具有统计意义，本文将 TTS 实验组织为三层：单因素实验，用于比较是否开启 TTS 以及不同 budget；两两组合实验，用于比较 DDIM+TTS、CFG+TTS 的相互作用；三因素联合实验，用于比较 DDIM、CFG、TTS 同时开启时是否存在部署上更优的折中组合。

三层实验设计的逻辑是：单因素实验确认 TTS 本身的有效性和最优 budget 范围；两两组合实验检验 TTS 与其他优化手段之间是否存在交互效应；三因素联合实验给出面向实际部署的推荐配置。

\subsection{结果与分析}

在讨论具体数值前，需要先澄清一个容易混淆的概念层次，以避免``默认生成 8 条候选''与``TTS-8''发生语义重合。NoMaD 扩散策略头的每次前向本身会以批次形式并行生成若干条候选轨迹（本文固定为 8 条），这一批次规格由扩散头本身决定，与是否启用 TTS 无关。TTS 在此基础上额外引入两个正交的组件：一是候选池预算 $K$（即 \texttt{tts\_budget}），当 $K > \texttt{num\_samples}$ 时通过多次扩散采样把候选池从默认的 8 条扩展到 $K$ 条；二是评分筛选器，对池内的 $K$ 条候选按多目标评分排序，保留 top-$k$ 条作为执行输出。因此，实验配置中的``No TTS''与``TTS-8''都只触发一次扩散采样、生成同样的 8 条候选，差别只在于前者把候选集原样送入下游统计，后者多了一步基于评分的排序与 top-$k$ 选择；而 TTS-16 和 TTS-32 则分别对应 2 次和 4 次扩散采样，用于真正扩展候选池规模。

TTS 实验的核心问题不是``是否绝对提升所有指标''，而是``是否值得把 DDIM 节省下来的预算重新分配给候选搜索''。本实验在 12 个统一离线 case 上比较 DDIM 步数、CFG 权重与 TTS budget 的组合，表~\ref{tab:tts-results} 给出在 \texttt{DDIM-2}、$w=0$ 条件下的单因素结果。

表中的单因素结果可以分解为两种不同来源的收益。从 No TTS 到 TTS-8，综合评分由 8.157 上升到 9.024，前进性由 9.010 上升到 9.697，而时延从 7.00\,ms 变为 6.89\,ms（两者在噪声范围内等价）——这段增益完全来自TTS，在同一批 8 条候选上额外执行一次排序与 top-$k$ 选择，几乎没有采样开销。从 TTS-8 到 TTS-16 再到 TTS-32，时延分别上升到约 2 倍和 4 倍，对应 1 次、2 次和 4 次扩散采样批次，这一段增益才真正来自``候选池扩容''：TTS-16 的综合评分 9.124 仅比 TTS-8 高 0.10，而 TTS-32 的综合评分反而回落到 8.825。TTS-8 在三因素联合排序（表~\ref{tab:tts-joint-top}）中综合表现最优，它近乎无时延，达到了 TTS 算法的收益，同时把剩余预算留给 DDIM 步数与 CFG 权重的组合。

\section{视觉编码器升级实验}

\subsection{实验目标}

视觉编码器升级实验的内容是在统一框架下对候选编码器进行公平训练，目的是在控制变量条件下评估不同编码器的表征潜力。

\subsection{候选编码器结构与对比}

本文在 EfficientNet-B0 之外纳入三类视觉骨干作为升级候选。DINOv2-Small\cite{dinov2_2023} 基于 Vision Transformer 架构，将图像切分为固定大小 patch 后送入 12 层 Transformer 编码器，参数量约 22\,M；自监督预训练赋予其较强的跨域泛化性，全局自注意力对远距离方向判断更敏感。ConvNeXt-Tiny\cite{convnext2022} 是借鉴 Transformer 设计原则的现代 CNN，采用更大卷积核、LayerNorm 与更少激活函数，在保留 CNN 局部归纳偏置的同时提升表征能力，参数量约 28\,M。ResNet-50\cite{resnet2016} 作为经典残差 CNN 提供稳定基线，结构成熟、权重广泛可用，参数量约 25\,M。三者与 EfficientNet-B0 的 MBConv（5.3\,M）形成``自监督 ViT、现代 CNN、经典 CNN''的对照，覆盖表征机制与参数量两条对比维度。

\subsection{特征维度对齐}

四种编码器的原始输出维度并不一致：EfficientNet-B0 输出 1280 维，DINOv2-Small 输出 384 维，ConvNeXt-Tiny 输出 768 维，ResNet-50 输出 2048 维。为保证公平对比，本文在每个编码器输出端附加一个线性投影层，将原始特征统一映射到固定 token 维度 $d$：
\begin{equation}
\mathbf{z} = W_{\text{proj}} \cdot \mathbf{f}_{\text{enc}} + \mathbf{b}_{\text{proj}},
\end{equation}
其中 $\mathbf{f}_{\text{enc}}$ 为编码器原始输出，$W_{\text{proj}} \in \mathbb{R}^{d \times d_{\text{enc}}}$ 为投影矩阵，与下游模块联合训练。投影后所有编码器在相同信息瓶颈下进入距离预测头与扩散策略头，避免条件空间容量差异干扰对比结果。


\subsection{训练配置}

在 GoStanford 数据集上对四种编码器分别进行 100 轮训练，batch size为 32，学习率与优化器配置统一。所有 backbone 参数参与微调，以便在相同训练轮数下最大化各编码器的适配空间。

\subsection{实验结果与分析}

四种编码器在相同离线 case、相同 DDPM-10 采样设置下的代理指标如表~\ref{tab:encoder-results} 所示。从指标分布看，各编码器在不同维度上表现各有侧重：ResNet-50 在 diversity（0.9824）与 forward progress（7.980）上最高，候选轨迹最分散、前进性最强；EfficientNet-B0 的 smoothness 最低（0.0725），原始基线在轨迹平滑性上仍具有优势；DINOv2-Small 与 ConvNeXt-Tiny 在三项质量指标上处于中段。延迟方面，四种编码器单次前向延迟均在 $34\text{--}37\,\text{ms}$ 区间，差异显著小于 DDIM 步数变化所带来的影响，因此编码器选择主要受表征质量约束而非延迟约束。

由于 diversity、forward progress 与 smoothness 三者之间存在内在权衡——更分散的轨迹候选意味着更大的方向变化，因此 smoothness 通常下降——视觉编码器升级不是单一指标最大化问题，而是在多样性、前进性与平滑性之间寻找折中。本实验为第二阶段的部署训练提供了候选筛选依据。

基于上述结果，可得到四点阶段性结论。第一，在不改动训练结果的前提下，\texttt{ddim\_2} 是当前最值得进入闭环验证的加速配置。第二，CFG 的有效范围有限，更适合作为可调参数而不是默认固定设置。第三，TTS 的收益可进一步分解为``评分筛选''（在固有 8 条候选上做排序与 top-$k$ 选择，几乎零时延代价）与``候选池扩容''（$K>8$ 时多批次采样，时延线性增长且边际收益快速衰减）两部分，TTS-8 以筛选为主、代价可忽略，继续增大TTS的参数则只能取得有限的增益，因此部署上推荐以 TTS-8 为默认档位、TTS-16 作为可选的增强方式。第四，视觉编码器升级已完成四个训练权重的离线统计，但最终部署选择仍需结合闭环验证与真机条件共同判断。

\subsection{优化方法之间的关系}

四种优化方法并不处在同一层级。视觉编码器升级位于视觉条件层，改变的是历史观察和目标图像进入模型后的特征表达；DDIM 与 CFG 位于扩散采样层，改变的是给定视觉条件后轨迹样本的生成方式；TTS 位于候选选择层，改变的是生成多条候选轨迹之后如何筛选最终执行轨迹。表~\ref{tab:optimization-role-summary} 总结了各方法的作用位置与实验含义。

因此，DDIM、CFG 与 TTS 更适合被写成统一推理层内部的层级组合：先由 DDIM 决定每条候选轨迹的去噪步数与生成速度，再由 CFG 决定采样过程中条件信号的放大程度，最后由 TTS 在候选轨迹集合上进行评分和选择。三者并不是简单并列相加，而是在``生成单条轨迹--增强条件响应--筛选候选轨迹''的流水线上依次发挥作用。算法~\ref{algo:inference-pipeline} 给出了四种优化方法在一次高层推理周期内的具体执行顺序，说明它们是如何在同一组观察输入上从``视觉表征—去噪采样—条件引导—候选筛选''逐层组合，最终输出一条供中层控制器跟踪的执行轨迹。

\begin{algorithm}[htb]
    \caption{统一推理模块在单次高层周期内的执行流程}
    \label{algo:inference-pipeline}
    \SetAlgoLined
    \KwIn{历史观察 $\mathcal{O}_t = \{I_{t-K},\ldots,I_t\}$，目标图像 $I_g$；视觉编码器权重 $\theta_{\text{enc}}$；DDIM 步数 $S$；CFG 权重 $w$；TTS 候选预算 $K$；扩散头每次前向产生的候选数 $N_0=8$}
    \KwOut{执行轨迹 $\mathbf{A}^\ast \in \mathbb{R}^{H\times 2}$}
    \BlankLine
    \tcp{1. 视觉编码器升级层：根据 $\theta_{\text{enc}}$ 提取 token，得到统一条件向量}
    $\mathbf{c} \leftarrow \text{VisionEncoder}_{\theta_{\text{enc}}}(\mathcal{O}_t, I_g)$\;
    $\mathbf{c}_\varnothing \leftarrow \text{VisionEncoder}_{\theta_{\text{enc}}}(\mathcal{O}_t, \text{mask})$\;
    \BlankLine
    \tcp{2. DDIM 采样层：用 $S$ 步 DDIM 一次性生成 $N_0$ 条候选轨迹}
    $M \leftarrow \lceil K / N_0 \rceil$\tcp*{扩散批次数；$K=N_0=8$ 时 $M=1$}
    $\mathcal{C} \leftarrow \emptyset$\;
    \For{$m \leftarrow 1$ \KwTo $M$}{
        $\mathbf{x}_S \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$，形状为 $N_0 \times H \times 2$\;
        \For{$s \leftarrow S$ \KwTo $1$}{
            \tcp{3. CFG 引导层：在每个去噪步同时跑条件与无条件分支并外推}
            $\boldsymbol{\epsilon}_{\text{cond}} \leftarrow \boldsymbol{\epsilon}_\theta(\mathbf{x}_s, s, \mathbf{c})$\;
            \uIf{$w \neq 0$}{
                $\boldsymbol{\epsilon}_{\text{uncond}} \leftarrow \boldsymbol{\epsilon}_\theta(\mathbf{x}_s, s, \mathbf{c}_\varnothing)$\;
                $\boldsymbol{\epsilon} \leftarrow (1+w)\boldsymbol{\epsilon}_{\text{cond}} - w\boldsymbol{\epsilon}_{\text{uncond}}$\;
            }
            \Else{
                $\boldsymbol{\epsilon} \leftarrow \boldsymbol{\epsilon}_{\text{cond}}$\;
            }
            $\mathbf{x}_{s-1} \leftarrow \text{DDIMStep}(\mathbf{x}_s, \boldsymbol{\epsilon}, s)$\;
        }
        $\mathcal{C} \leftarrow \mathcal{C} \cup \{\mathbf{x}_0^{(1)}, \ldots, \mathbf{x}_0^{(N_0)}\}$\tcp*{累积候选池}
    }
    \BlankLine
    \tcp{4. TTS 候选筛选层：对池内 $|\mathcal{C}|$ 条候选打分并取最优}
    \ForEach{$\mathbf{A}^{(i)} \in \mathcal{C}$}{
        $s_i \leftarrow \beta_1 \cdot \text{FP}(\mathbf{A}^{(i)}) - \beta_2 \cdot \text{LA}(\mathbf{A}^{(i)}) - \beta_3 \cdot \text{Smooth}(\mathbf{A}^{(i)})$\;
    }
    $\mathbf{A}^\ast \leftarrow \arg\max_{i} s_i$\;
    \Return $\mathbf{A}^\ast$\;
\end{algorithm}

算法~\ref{algo:inference-pipeline} 揭示了四种优化方法的层级关系：视觉编码器升级位于最外层，决定了条件向量 $\mathbf{c}$ 与 $\mathbf{c}_\varnothing$ 的特征分布；DDIM 步数 $S$ 控制中间去噪循环的长度，是单条候选轨迹生成成本的主要来源；CFG 权重 $w$ 在每一去噪步内通过条件/无条件外推增强目标响应，代价是每步多一次前向；TTS 预算 $K$ 决定候选池规模，当 $K=N_0=8$ 时只触发一次扩散批次（仅做评分排序），当 $K>N_0$ 时通过额外批次扩展候选池。本文最终采用的默认配置为 $S=2,\,w=0,\,K=8$，对应``两步 DDIM 采样一批 8 条候选 $\to$ 跳过 CFG 外推 $\to$ 直接对池内 8 条候选评分取最优''，这一组合在算法~\ref{algo:inference-pipeline} 的流程上把每一层的代价都压到最低，同时保留了多模态采样和评分筛选两项核心收益。

视觉编码器升级与前三者既相对独立，又存在间接联系。独立性体现在工程接口上：编码器由 \texttt{policy\_config} 与 \texttt{policy\_checkpoint} 决定，而 DDIM、CFG、TTS 由推理参数决定，只要模型保持 NoMaD 兼容输出，下游状态机和平台接口无需修改。联系则体现在条件分布上：更换编码器会改变历史观察和目标图像的 token 表达，从而同时影响距离预测头和扩散策略头。补齐后的编码器 $\times$ DDIM/TTS/CFG 联合消融（见表~\ref{tab:encoder-ddim-joint}--\ref{tab:encoder-cfg-joint}）给出的经验结论是：DDIM 步数选择与 CFG 权重选择对编码器替换具有鲁棒性，其中 DDIM-2 在四个编码器上都是默认最优档，CFG-1/2 在任何一个编码器上都无法换取有意义的质量增益；唯一与编码器耦合的是 TTS-8 的筛选增益——初始候选 Diversity 越高（如 ResNet-50），TTS-8 的相对提升越大。换言之，前三个优化中的``DDIM+CFG''部分在既定视觉条件空间内调整推理过程而不受编码器影响，TTS 部分则在一定程度上继承编码器带来的分布变化，视觉编码器升级则是在源头上改变条件空间。

\subsection{消融验证与编码器联合补充}

本章已经完成了主要算法变量的单因素消融和联合消融。DDIM 实验固定模型与数据 case，仅改变采样步数，验证了 \texttt{DDIM-2} 的速度收益与 \texttt{DDIM-1} 的失效边界；CFG 实验固定模型，仅改变引导强度，说明其质量收益不足以抵消默认开启时的时延代价；TTS 实验固定 DDIM 与 CFG 条件，比较不同候选预算，说明主要收益来自 TTS-8 的低成本筛选；视觉编码器实验在统一训练配置下比较四个训练权重，证明了编码器替换框架可训练、可评估、可接入闭环。

跨视觉编码器的联合消融对判断``DDIM/CFG/TTS 的最优参数是否稳定''至关重要：如果更换编码器会改变候选轨迹的多样性和平滑性，那么 TTS 的评分选择、CFG 的目标引导强度和 DDIM 的少步近似误差都可能随之漂移。本文在相同的离线 case 构造规则下进行实验，完成了``编码器 $\times$ DDIM/CFG/TTS''联合矩阵，4 个训练权重（EfficientNet-B0、DINOv2-Small、ConvNeXt-Tiny、ResNet-50）统一以 DDIM 调度器为基础，分别扫描 DDIM-2/3/5 步数、TTS-0/8/16 候选预算以及 CFG-0/1/2 引导权重，每个配置在 12 个离线 case 上重复 3 次。CFG 一项限定在 EfficientNet-B0 与 ResNet-50 这两个初始多样性差异最大的编码器上，以小规模方式验证目标引导是否会放大编码器差异。三组结果分别由表~\ref{tab:encoder-ddim-joint}、表~\ref{tab:encoder-tts-joint} 和表~\ref{tab:encoder-cfg-joint} 给出，所有条目均已带 CI95 置信区间。

\subsection{最终算法框架确定}

综合本章的全部离线实验，本文将最终算法框架确定为：EfficientNet-B0 视觉编码器、\texttt{DDIM-2} 采样、\texttt{CFG=0}、\texttt{TTS-8}。这一组配置随后被提炼为系统层的``统一推理模块''：在第~\ref{sec:unified-arch} 节定义的分层架构中，编码器权重由 \texttt{policy\_checkpoint} 选定，DDIM 步数、CFG 权重与 TTS 候选预算分别由 \texttt{ddim\_steps}、\texttt{cfg\_weight} 与 \texttt{tts\_budget} 三个推理参数承载，而算法~\ref{algo:inference-pipeline} 描述的执行顺序则成为该模块对外提供的标准推理流程。换言之，本章实验的目的不是给出一组孤立的最佳数值，而是确定推理模块在部署侧应当采用的默认参数与执行模板，使下游状态机、导航主机和平台后端只需通过修改配置即可复用同一套高层推理代码。

为了适配不同部署需求，可在该默认配置之上给出三个候选层级。低时延默认方案与上述最终配置一致，是统一推理模块的出厂默认值；稳定方案将 DDIM 步数提高到 3 或 5，并保持 \texttt{CFG=0} 与 \texttt{TTS-8}，用于对推理时延不敏感、对轨迹光滑性要求更高的场景；复杂场景增强方案在默认配置上额外开启 \texttt{CFG=0.5/1.0} 或 \texttt{TTS-16} 作为可调项，用于强目标牵引或更激进的候选筛选。三种层级共享同一份推理模块代码与同一组对外接口，差别仅在配置文件中的几行参数。视觉编码器升级实验的价值则在于建立``可替换、可重训、可评测''的编码器训练与评估框架，并发现潜在的视觉编码器替换候选，而不是直接证明 DINOv2 或 ResNet-50 已经全面优于原始的 EfficientNet-B0；该框架同样以 \texttt{policy\_config}/\texttt{policy\_checkpoint} 的形式接入统一推理模块，对后续章节的系统集成保持透明。

\section{本章小结}

本章围绕 NoMaD 的算法层问题展开研究。首先从 MDP 视角对视觉导航任务进行了形式化建模，分析了条件轨迹分布与传统策略的联系，并论证了 waypoint 表示在平台无关性、多模态表达和闭环控制方面的优势。其次，复现并梳理了 NoMaD 的视觉编码器架构、token 构建过程、训练目标和统一推理接口。在此基础上，以基线实验为参照，对 DDIM 推理加速、CFG 引导增强、TTS 推理时搜索和视觉编码器升级进行了系统分析。
