# 项目理解与论文定位

生成日期：2026-05-17

## 1. 我对仓库主线的理解

这个仓库不是一个单纯复现 NoMaD 的训练仓库，而是在 Berkeley Visual Navigation Transformer / NoMaD 代码基础上，把 action-diffusion visual navigation 部署到 DeepRobotics Lite3 四足机器人上的完整工程与实验系统。

项目主线可以概括为：

> 使用 NoMaD 风格的视觉目标导航策略，从当前相机观测和目标/拓扑图像中预测未来 waypoint 序列；再通过中层 PD/速度映射和底层 Lite3 控制接口，把扩散策略输出变成四足机器人可执行的运动命令；同时用 DDIM、CFG、TTS 和视觉编码器替换来解决 Jetson Orin 上的实时性与鲁棒性问题。

## 2. 代码与文档中的关键模块

- `train/`：保留并整理了 GNM、ViNT、NoMaD 的训练入口、数据加载、扩散损失、EMA eval 和模型构造。
- `train/vint_train/models/nomad/`：NoMaD 的视觉编码器、距离预测头、扩散噪声预测网络等核心结构。
- `scripts/shared/nomad_inference.py`：统一推理模块，支持 DDPM/DDIM、CFG、TTS、多样本采样、不同视觉编码器和图像 resize 策略，是“论文系统贡献”的核心代码之一。
- `scripts/nomad_eval_common.py` 与 `scripts/encoder_joint_ablation_experiment.py`：离线调度器、CFG、TTS、视觉编码器等实验的统一评测脚手架。
- `scripts/simulation/lite3_system/`：Lite3 分层系统，包括高层 NoMaD 策略、中层 PD、低层平台接口、状态机、拓扑地图、任务管理、MuJoCo 闭环。
- `scripts/deployment/lite3_real_bridge.py`：Jetson Orin + Lite3 实机桥接，含相机线程、UDP 控制、heartbeat、速度命令刷新、安全停机和连接状态监控。
- `scripts/deployment/nomad_navigation_host.py`：统一导航主机，支持 MuJoCo、real backend、交互任务、拓扑图验证、视频保存和任务队列。
- `论文/contents/`：中文毕业论文主体，已经形成了从算法、系统、仿真、实机到结论的完整叙事。
- `results/`：DDIM/CFG/TTS/encoder、MuJoCo 健康检查、闭环扫描等结果摘要与证据索引。

## 3. 当前最强论文叙事

不建议把论文写成“我提出了一个新的视觉导航模型”，因为核心策略来自 NoMaD，模型结构创新不足以支撑顶会算法论文。

更合适的英文论文定位是：

> A deployment-oriented study of real-time diffusion-policy visual goal navigation on a resource-constrained quadruped robot, with system integration, inference acceleration, closed-loop simulation, and real-robot validation.

可以强调的贡献是：

1. **四足机器人部署栈**：把 NoMaD 的图像目标导航策略迁移到 Lite3，从图像预处理、拓扑目标选择、扩散采样、waypoint 选择、中层 PD 到底层 UDP 控制形成完整闭环。
2. **实时扩散推理优化**：系统比较 DDPM、DDIM、CFG、TTS、不同视觉编码器和样本预算，给出 Jetson Orin 上可运行的实时配置。
3. **仿真到实机验证**：用 MuJoCo 多场景闭环和 Lite3 室内多场景实机实验验证部署可行性，并报告失败案例和室外 zero-shot 限制。
4. **工程安全机制**：状态机、heartbeat、twist 刷新、安全超时、跌倒检测、连接陈旧检测、探索/导航切换等机制让学习策略能够在真实四足平台上运行。

## 4. 现有结果中最能支撑投稿的证据

来自中文论文和 `results/summary` 的关键结论包括：

- DDIM-2 相比 DDPM 有约 4.84 倍推理加速，是当前最清晰的实时性贡献。
- Jetson Orin 上完整实机系统可达到约 7 Hz 量级的独立运行频率。
- 室内真实场景中，DDPM baseline、DDIM-2、DDIM-2 + CFG + TTS、DDIM-3 等配置均有多次成功导航记录。
- MuJoCo easy/medium/hard 场景中闭环导航能够完成，说明策略可以接入四足运动闭环。
- 室外 zero-shot 暴露了强光、草地、复杂纹理和开放空间中的视觉分布外问题，这对论文 discussion 很有价值。

## 5. 当前最大审稿风险

如果按顶会标准看，风险主要有五个：

1. **算法新意不足**：NoMaD、DDIM、CFG、TTS 都不是你原创；必须把贡献写成系统部署与实证优化。
2. **真实机器人统计量偏小**：如果每个配置只有少量 runs，RA-L/CoRL 审稿人会要求更多重复实验、置信区间和失败分析。
3. **MuJoCo route stabilizer 的混杂因素**：仿真中如果用了路线稳定器，不能把结果解释为纯 NoMaD 策略能力。
4. **缺少强 baseline**：目前主要是 NoMaD 内部配置对比。若想投高水平 venue，最好加入 ViNT/GNM、无 TTS、无 DDIM、无拓扑窗口或传统视觉导航控制的对比。
5. **室外泛化不足**：这不是不能投稿，但必须诚实写成 limitation，而不是回避。

## 6. 推荐论文类型

最匹配的是 6-8 页机器人系统/学习部署论文：

- 标题关键词应包含：`real-time`、`diffusion policy`、`visual goal navigation`、`quadruped robot`、`deployment`。
- 摘要不要过度宣传“state-of-the-art”；应强调“a systematic deployment and evaluation study”。
- 主图建议画成四层系统图：Visual Topological Goal Selection -> Diffusion Waypoint Policy -> PD/Twist Adapter -> Lite3 Robot.

## 7. 最不建议的写法

- 不建议声称“提出一种新的通用视觉导航算法”。
- 不建议把 MuJoCo 带 stabilizer 的成功率写成纯策略成功率。
- 不建议只展示成功视频而缺少失败统计。
- 不建议把 outdoor zero-shot 失败藏起来；诚实讨论反而能提升可信度。
