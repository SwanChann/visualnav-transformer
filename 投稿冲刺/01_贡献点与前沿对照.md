# 贡献点与前沿对照

更新日期：2026-07-07
目的：逐点讲清楚本文到底做什么、相关领域已经做到什么程度、本文应该如何避开过强 claim 并形成 RA-L 可审的贡献边界。

## 0. 总定位

本文不应写成“提出新的视觉导航基础模型”，也不应写成“解决跨形态 zero-shot 导航”。更稳的 RA-L 主线是：

> 在冻结的 NoMaD-style diffusion visual navigation policy 上，研究资源受限 Lite3 四足机器人部署时，推理配置、系统适配和实时控制如何共同决定 latency、trajectory quality 和 closed-loop robustness。

这句话里有三个关键限制：

1. **frozen policy**：不重新训练 NavDP/SIDP/X-Nav 级别的大模型。
2. **Lite3 deployment**：贡献落在真实四足平台部署和评估，而不是泛泛的视觉导航 benchmark。
3. **time-quality trade-off**：核心实验不是单点成功率，而是 DDIM/CFG/TTS/encoder 在延迟和质量之间的取舍。

## 1. Point A：视觉导航基础模型不是本文原创

### 本文要说什么

本文使用 NoMaD-style 图像目标扩散导航策略作为高层 waypoint generator，并把它接入 Lite3 四足机器人控制栈。这里的 policy backbone、goal-conditioned visual navigation 和 topological image-goal navigation 不是本文原创。

### 别人已经做到什么程度

| 工作 | 已经做到的程度 | 对本文的压力 |
|---|---|---|
| GNM | 用多机器人真实轨迹训练通用 goal-conditioned visual navigation model，强调 temporal context 和 normalized action space。 | 说明跨机器人泛化需要数据和 action 表示设计，不能只靠 adapter 强 claim。 |
| ViNT | 用 Transformer 和通用 goal-reaching objective 训练视觉导航 foundation model，可接拓扑图和长程导航。 | 说明“视觉目标 + 拓扑图 + 局部策略”已经是成熟系统形态。 |
| NoMaD | 用 goal-masked diffusion policy 统一 goal-directed navigation 和 exploration，并在真实移动机器人上部署。 | 本文必须承认 build upon NoMaD-style policy，不能把模型本身当贡献。 |

### 本文的合理贡献边界

可以说：

> We build on visual navigation models and NoMaD-style diffusion waypoint policies, and study their deployment-time behavior on a resource-constrained quadruped platform.

不要说：

> We propose a new visual navigation foundation model.

### RA-L 中对应位置

- Introduction：一句话承认 NoMaD-style backbone。
- Method：单独一小节 `NoMaD-style Visual Navigation Backbone`，明确 weights/architecture 不是贡献。
- Related Work：把 GNM、ViNT、NoMaD 放第一段。

## 2. Point B：时间-质量推理权衡是本文主贡献

### 本文要说什么

扩散策略能生成多模态 waypoint，但迭代去噪带来实时延迟。本文把 DDIM steps、CFG weight、TTS/candidate budget 和 encoder choice 统一成 inference configuration space：

```text
c = (encoder, sampler, steps, cfg_weight, tts_budget)
```

目标不是发明一个新 sampler，而是测量：

```text
maximize Q(c)
subject to latency_p95(c) <= B
```

其中 `Q(c)` 来自 forward progress、smoothness、invalid ratio、diversity 和 quality/ms 等离线 proxy，并用 MuJoCo 和冻结真机证据复核。

### 别人已经做到什么程度

| 工作 | 已经做到的程度 | 对本文的压力 |
|---|---|---|
| NaviBridger | 用 denoising diffusion bridge 从 informative prior action 出发，而不是从高斯噪声开始，减少冗余去噪。 | 说明 DDIM 不是唯一加速路线；本文只能说低改动配置评估。 |
| NavDP | 大规模仿真训练 diffusion policy，并用 critic 选择候选轨迹，实现跨形态 zero-shot。 | 本文不能 claim 比它更强，只能 claim fixed-policy deployment。 |
| SIDP | 用 reward-guided self-imitation 减少 generate-then-filter 依赖，在 Jetson Orin Nano 报告 110 ms vs NavDP 273 ms。 | 本文不能说 TTS 是最终方案，只能说它是候选预算变量。 |
| NaviDiffusor | 推理时加入可微 cost guidance，无需重训地提升路径有效性。 | 本文没有场景 cost model，不能 claim safety guidance。 |
| SRIF | 将 diffusion policy 转为 ranking model，结合局部地图约束做更安全推理。 | 如果本文做 TTS，必须诚实说是 budget study，不是新的 safe ranking。 |
| Fisher-Preserving Guidance | 用 training-free manifold-preserving guidance 降低 off-manifold drift，单步 backward 可实时使用。 | 本文的 CFG/TTS 不提供 formal safety 或 manifold guarantee。 |
| RTI-DP | 在 manipulation 中用上一时刻预测 warm start，大幅降低 diffusion policy 推理时间。 | 说明实时 diffusion inference 是独立前沿；本文可作为导航部署实证。 |
| Realtime-VLA FLASH | 用 draft model + verification + fallback 加速 diffusion-based VLA。 | 本文不训练 draft model，只做静态配置表。 |

### 本文的合理贡献边界

可以说：

> We provide a systematic deployment-time analysis of low-modification inference choices for a frozen NoMaD-style visual navigation policy.

不要说：

> We solve diffusion policy real-time inference.

### RA-L 中对应位置

- Contribution 2。
- Method：`Time-Quality Inference Space`。
- Experiments：Offline Pareto 是正文核心图。
- Discussion：说明 bridge prior、self-imitation、Fisher guidance 是 future work。

## 3. Point C：Lite3 四足部署栈是系统贡献

### 本文要说什么

本文把视觉导航策略真正接到 Lite3：camera/topomap 输入，NoMaD-style policy 输出 waypoint，adapter 转换成速度命令，再通过 Lite3 控制桥和安全机制执行。这个贡献是工程系统和真实部署证据，不是新 locomotion controller。

### 别人已经做到什么程度

| 工作 | 已经做到的程度 | 对本文的压力 |
|---|---|---|
| ANYmal Parkour | 分层 RL 系统实现四足敏捷导航，感知、导航、locomotion 异步运行，并在真机上通过复杂障碍。 | 本文不能比敏捷运动能力；只能强调视觉目标 diffusion policy 的部署约束。 |
| Motion Anisotropy Awareness | 用 kinodynamic planning、trajectory optimization 和 NMPC 显式处理四足运动各向异性。 | 本文 adapter 只是保守转换，不是动力学最优规划。 |
| X-Nav | 用多专家 RL 和 policy distillation 训练可跨轮式/四足的端到端导航策略。 | 本文不能 claim cross-embodiment。 |
| CE-Nav | 用 IL-then-RL 解耦几何专家和机器人动力学 refiner，实现跨形态 local navigation。 | 真正跨形态需要训练和动力学适配，不是简单换接口。 |

### 本文的合理贡献边界

可以说：

> We present a Lite3 deployment stack with waypoint-to-velocity adaptation, command limiting, stale-frame protection, heartbeat, timeout, and emergency-stop aware execution.

不要说：

> We propose a new quadruped locomotion or cross-embodiment navigation method.

### RA-L 中对应位置

- Method：`Waypoint-to-Velocity Adapter` 和 `Lite3 Safety Bridge`。
- Table I：平台、控制频率、视觉输入、推理设备、速度限制。
- Fig. 1：系统总览。

## 4. Point D：三层证据链是本文可信度来源

### 本文要说什么

由于真机不再继续做，本文必须把证据分层：

1. **Offline**：统计强度最高，用于证明推理配置的 latency-quality Pareto。
2. **MuJoCo**：验证离线推荐配置在 Lite3 闭环中可执行。
3. **Frozen real robot**：用已有视频和 timing profile 证明真实系统跑通过，并展示失败边界。

### 别人已经做到什么程度

| 工作 | 已经做到的程度 | 对本文的压力 |
|---|---|---|
| NavDP | 纯仿真生成大规模数据，报告 363.2 km trajectories、1244 scenes，并在 quadruped/wheeled/humanoid 上 zero-shot。 | 本文不能 pretend 大规模 benchmark，只能做部署实证。 |
| SIDP | 综合仿真 benchmark + 多平台真机，强调效率和鲁棒性。 | 本文真机样本少，必须把统计结论放在线下/仿真。 |
| NoMaD | 真实移动机器人上多场景导航和探索验证。 | 本文要说明差异在四足部署和推理配置分析。 |
| X-Nav / CE-Nav | 有完整训练、仿真、真机跨形态链条。 | 本文不再主张跨形态。 |

### 本文的合理贡献边界

可以说：

> Real-robot trials are used as representative anchor validation; quantitative conclusions are primarily supported by offline and MuJoCo experiments.

不要说：

> We provide statistically conclusive real-world evaluation.

### RA-L 中对应位置

- Experiments 开头：明确 evidence levels。
- Table II：offline Pareto。
- Table III：MuJoCo closed-loop。
- Table IV：frozen real-robot evidence。
- Limitation：真机样本少、route stabilizer、domain shift。

## 5. Point E：失败和 domain shift 是本文必须正面写的内容

### 本文要说什么

Lite3 已有室外、草地、强光、开放空间、重复纹理等失败素材。不要隐藏失败；要把失败写成本文的科学价值：轻量推理配置只能改善时间-质量权衡，不能根治视觉 domain shift、目标歧义和安全约束。

### 别人已经做到什么程度

| 工作 | 已经做到的程度 | 对本文的启发 |
|---|---|---|
| Beyond Imitation | 用 GRPO 对 diffusion navigation policy 做 RL fine-tuning，在 unseen scenes 中提高 success/SPL 并减少碰撞。 | 真正解决 domain shift 可能需要在线反馈和训练。 |
| NavDP real-to-sim | 用 Gaussian Splatting 做 real-to-sim fine-tuning，报告 success rate 提升。 | 室外/真实域问题不是调 DDIM 就能解决。 |
| Navigation World Models | 用可控视频生成预测未来视觉，支持 trajectory simulation 和 ranking。 | 长程目标混淆和可达性评估可以交给 world model。 |
| NavWAM | 把 future observation、goal progress 和 action chunk 联合建模。 | 前沿正在转向 world-action model，本文只能作为部署实证。 |
| Fisher / SRIF / NaviDiffusor | 用 guidance、ranking、cost 或 manifold 约束提升安全性。 | 本文的 failure analysis 可以指出未来 selector 的方向。 |

### 本文的合理贡献边界

可以说：

> Outdoor failures reveal the limitation of lightweight inference tuning and motivate future work on adaptation, cost-guided sampling, and world-model-based evaluation.

不要说：

> The method robustly generalizes to outdoor environments.

### RA-L 中对应位置

- Experiments：`Failure and Domain Shift Analysis`。
- Fig. 4：成功和失败关键帧并列。
- Discussion：把失败对应到未来工作，不要把 limitation 写成一句话带过。

## 6. 最终贡献写法

推荐三条贡献：

1. **Deployment stack**：A Lite3 quadruped deployment stack for NoMaD-style diffusion visual goal navigation, including topological image-goal selection, waypoint-to-velocity adaptation, and safety-aware command execution.
2. **Time-quality analysis**：A systematic latency-quality analysis of DDIM steps, CFG weight, test-time candidate budget, and encoder choice for a frozen diffusion navigation policy.
3. **Evidence chain**：A three-level evaluation using offline Pareto analysis, MuJoCo closed-loop validation, and frozen real-robot trials with explicit failure/domain-shift analysis.

## 7. 一句话差异化

面对强相关工作，本文的差异化应写成：

> Unlike recent methods that improve diffusion navigation through large-scale retraining, critic learning, self-imitation, bridge priors, or manifold guidance, we study the practical no-retraining setting: how to select and validate inference configurations for a pretrained NoMaD-style policy on a resource-constrained quadruped robot.
