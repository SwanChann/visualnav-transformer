### RA-L 版本建议

RA-L 篇幅短，建议聚焦：

> Real-time deployment of diffusion-policy visual goal navigation on a quadruped robot.

主线结构：

- 1 页 Introduction + contributions。
- 1 页 system overview。
- 1 页 inference acceleration and waypoint adapter。
- 2 页 experiments。
- 0.5 页 limitations。
- 0.5 页 conclusion。

### T-RL 版本建议

T-RL 可以写得更像 robot learning：

- 更系统地分析 DDIM、CFG、TTS 对 diffusion policy action distribution 的影响。
- 比较视觉编码器对闭环导航和泛化的影响。
- 加入更多 sim-to-real 和 outdoor domain shift 分析。
- 如果可能，增加一个轻量 learning adaptation 或 domain randomization 实验。

## 4. 必补实验清单

### P0：真实机器人统计

这是最重要的一项。

建议最少配置：

| 配置 | Runs | 指标 |
|---|---:|---|
| DDPM baseline | >= 10 | success, time, interventions, frequency |
| DDIM-2 | >= 10 | success, time, interventions, frequency |
| DDIM-2 + TTS-8 | >= 10 | success, time, interventions, frequency |
| DDIM-2 + CFG + TTS-8 | >= 10 | success, time, interventions, frequency |

更理想是每个配置 20 runs，并报告 95% confidence interval。

### P0：强 baseline

至少需要一个“审稿人认可”的对比：

- NoMaD DDPM 原始配置。
- NoMaD DDIM no TTS。
- NoMaD DDIM + TTS。
- 如果能跑，加入 ViNT 或 GNM waypoint policy。
- 如果不能跑完整 baseline，必须解释接口/模型限制，并用内部 ablation 弥补。

### P0：真实视频和失败案例

每篇机器人论文都需要视频支撑。

视频建议包含：

- Lite3 室内成功导航。
- 拓扑目标切换可视化。
- 不同配置速度差异。
- 室外 zero-shot 成功与失败。
- 失败原因标注：强光、草地纹理、开放区域、目标混淆。

### P1：MuJoCo 去混杂

当前 MuJoCo route stabilizer 会让审稿人质疑策略闭环能力。

建议补：

- stabilizer on/off 对比。
- 如果 off 后失败，也如实写：sim stabilizer is used to compensate for quadruped locomotion-controller mismatch, while real robot uses native velocity controller。
- 把 MuJoCo 结果定位成 system integration validation，不要写成最终性能证明。

### P1：拓扑图密度和目标距离

视觉导航论文常被问 topomap 是否“作弊”。

建议补：

- 节点间距 0.25m / 0.5m / 1.0m 对成功率影响。
- 目标距离 2m / 4m / 6m 对成功率影响。
- 滑动窗口半径对结果影响。

### P1：Jetson Orin 端实时性表

建议统一报告：

- visual encoder time。
- distance prediction time。
- diffusion sampling time。
- TTS scoring time。
- PD/controller overhead。
- end-to-end Hz。

### P2：消融和泛化

可加分但不是最紧急：

- image resize mode：stretch / crop / letterbox。
- waypoint index：1 / 2 / 3。
- TTS budget：1 / 4 / 8 / 16。
- CFG weight：0 / 1 / 2。
- encoder：EfficientNet-B0 / ResNet50 / ConvNeXt / DINOv2。
